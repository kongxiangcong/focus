# Teaching and checkpoint protocol

Advance exactly one selected node or remediation target. Resolve every cited anchor through the current source map and distinguish author claims, reported evidence, and instructional inference.

Frame the question, give the minimum anchored causal explanation, trace mechanism plus assumptions/tradeoffs, and ask one checkpoint tied to observable exit criteria. Persist the waiting interaction before presenting the question. Keep generated teaching separate from learner notes and preserve answers verbatim.

Use these verdicts:

| Verdict | Observable meaning | Consequence |
|---|---|---|
| `no-evidence` | No relevant learner answer | remain `learning` |
| `misconception` | Critical mechanism, assumption, or boundary is wrong | `needs-remediation` |
| `partial` | Some required points are absent | smallest neutral follow-up |
| `sufficient` | All required points, no critical error | `provisional` |
| `transfer` | Sufficient model applied unprompted to a new case | `verified-now` |

“懂了” is self-report only. During remediation, reteach the smallest diagnosed gap and test it without revealing a future assessment answer. Teaching never awards `retained`.
