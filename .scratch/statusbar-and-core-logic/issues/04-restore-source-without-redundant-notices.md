# 04: 切篇恢复精读位置并移除重复提示

**What to build:** 读者在精读模式下换篇时直接恢复目标文章已有的阅读位置。用来源标题、选中的阅读方式和内容反馈位置，并在需要时提供准备或重试。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 精读中从 A 切到 B 时恢复 B 的已选且就绪的 Reading Plan 及其持久位置。候选计划保持待读者显式启用，打开和切换阅读方式保持 Reading Cursor。
- [x] 延迟 A 的成功与失败响应后切到 B，A 的旧结果不能覆盖 B 的正文、状态或提示。来源与切换代际均须匹配才可更新。
- [x] 目标精读尚未就绪时，在对应区域显示真实准备进度或失败，读者可以准备、重试和切回对话。
- [x] 首次打开、切篇、切换阅读方式和恢复位置均不出现「正在阅读 xxx」「已打开」「已就绪」之类的浮层、弹框或横幅。
- [x] 保存笔记后的一次性查看反馈仍可用，刷新后不会残留过时的已保存提示。

## Comments

从精读切篇时恢复目标来源的已选计划和持久位置。工作台与 Host 回归覆盖迟到的选择及恢复响应、候选计划显式启用，以及准备失败后切回对话。
