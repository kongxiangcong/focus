# 09: 统一「重新阅读」，清理旧精读并开启新讨论

**What to build:** 将「新会话」「重新规划」和「重新阅读」合并为一个可确认的重读入口，留下整篇笔记和旧聊天归档，立即准备全新的精读计划与内容。

**Blocked by:** 06 全屏 Esc 逐层退出、证据保留与键盘焦点闭环

**Status:** ready-for-agent

- [ ] 在 06 的可聚焦确认框上升级文案，明确会清除精读进度、旧计划、小段笔记、句子备注和重点，整篇笔记会保留，确认后开启新对话。取消后数据、位置和会话保持原状。
- [ ] 确认后清除本篇旧精读计划和衍生精读内容、进度及局部批注。整篇笔记、原件、Parser Bundle 和无关资产仍可用。工作台统一展示「重新阅读」入口。
- [ ] 新讨论从空白对话上下文开始，旧讨论保留归档。检查新讨论首次模型请求，确保不会沿用旧消息或摘要。
- [ ] 确认后立即生成新计划与精读内容，就绪后从首段进入。生成失败时精读保持未开始，当前来源可重试，对话仍可用。
- [ ] 模拟 Host 重启、确认响应丢失、重复提交及旧写入迟到。重置能继续到一致结果，不会复活旧计划、进度、已清除笔记或旧上下文。生成重试沿用已完成的重置，不再次清理或新建讨论。
