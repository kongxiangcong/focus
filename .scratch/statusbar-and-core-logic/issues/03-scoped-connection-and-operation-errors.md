# 03: 重连清掉断线提示，错误留在所属位置

**What to build:** 读者在统一工作台中只看到当前来源的阅读错误，重连成功后可以继续处理此前的操作错误，并能从全局任务框辨认其他文章的后台失败。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**建议顺序**：排在 01 之后，以便复用已补齐的来源标识和成功问答退出规则。基础 SSE 与错误作用域可独立开展，全局任务标签的联调以 01 的投影为准。

- [ ] 同一工作台页面在路由、来源和阅读方式切换中保持单一 SSE 订阅，精读和对话共用快照。独立使用的阅读适配器继续工作。
- [ ] SSE 重连收到健康快照或健康轮询恢复后，断线提示退出。无关快照不会清除文档错误或笔记版本冲突。
- [ ] 来源错误在当前来源重新加载成功或切篇时退出。操作错误按本次尝试处理，在该操作重试成功、手动关闭或离开所属来源后退出阅读区。
- [ ] A 的问答及操作错误在 B 的阅读区和输入区不可见。A 的后台失败仍可在全局任务框按来源辨认。开篇或博客重新生成成功、来源删除及新尝试按作用域清理对应的过期错误。
