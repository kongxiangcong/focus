# 01: 成功任务退出，待处理工作保留

**What to build:** 让工作台各页面的任务摘要和任务框展示进行中、待审批、待处理及仍可见的失败。读者可以继续处理混合批次中的余项，且每个审批只有一个操作入口。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 覆盖问答、审批、阅读准备、开篇导读、博客、入库、批次和阅读记录整理。可见条目携带稳定的目标和尝试标识，已知来源的任务标明来源，并保留阶段、进度及可用操作。
- [ ] 首个反映成功的快照移除状态摘要、任务框和批次中的成功项，包括 Inbox 或批次列表仍有旧缓存的情形。刷新后仍隐藏，已删除条目也退出。
- [ ] 混合批次的待确认、暂停可继续、远端待核对和失败子项仍可见，原有确认、停止、查询、续接和重试各自可用。同一入库工作只显示一次。
- [ ] 成功问答从活跃运行投影退出，执行归档和完整业务记录仍可读取。审批失效后入口退出，实际问答结果沿用运行时结果。
- [ ] 阅读页和其他工作台页面均可操作当前审批，每次仅呈现一个操作入口。验证混合批次、成功退出和审批的正常及失效路径。
