# 05: 精读静止时停止逐帧采样

**What to build:** 精读页面只在滚动、内容与尺寸变化、流式跟随和有限的动画或位置保持期间更新位置，让闲置页面停止逐帧工作。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 用浏览器观测确认精读静止后滚动控制器零 rAF 唤醒，短暂位置保持和动画结束后同样恢复零唤醒。
- [x] 流式内容增量、尺寸与布局变化、内容展开及新的滚动操作可触发所需采样和位置恢复。
- [x] 手动滚动可暂停跟随，返回阅读位置和恢复跟随继续可用。覆盖流式期间和稳定内容两种场景。

## Comments

Chromium 在隔离 Host 的精读页观察到空闲和位置保持结束后各有 500 ms 零 rAF 请求。调整视口会重新调度采样。滚动回归覆盖锚点恢复、手动暂停跟随和返回位置。
