# 02: 「全部清空」只隐藏已结束的失败

**What to build:** 让读者一键清掉已经结束的失败提示，同时留下仍需操作的任务，并能通过原有入口恢复未完成工作。

**Blocked by:** 01 成功任务退出，待处理工作保留

**Status:** resolved

- [x] 使用 01 的尝试标识识别当前可清空的失败。运行中、待确认、暂停可继续、远端结果待核对的条目继续可见且可操作。
- [x] 刷新页面和 Host 重启后清空仍生效。清空只改变提示可见性，原任务、记录和恢复入口仍可用。
- [x] 新尝试再次失败时显示新提示。确认响应丢失后的请求重放和旧请求迟到均不能隐藏更新的尝试。重复点击和重放不产生无界的去重记录。
- [x] 清空后重复上传同一原件，恢复该原件的未完成任务和对应批次，并可找到原恢复操作。同批其他已隐藏子项仍隐藏，原解析任务不自动重跑。

## Comments

清空请求绑定快照中的失败尝试。Host 回归覆盖重启、请求重放、旧请求迟到和重复上传只恢复当前原件。Chromium 验证清空后的提示跨刷新隐藏，待确认原件仍可操作。
