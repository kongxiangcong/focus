# 06: 全屏 Esc 逐层退出、证据保留与键盘焦点闭环

**What to build:** 读者在全屏中按 Esc 逐层关闭浮层，退出后继续查证据。笔记抽屉、确认框和折叠导航支持连贯的键盘操作。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 全屏中有模态确认框、笔记抽屉或批注编辑器时，Esc 先关闭最上层；浮层都关闭后下一次 Esc 才退出全屏。用真实控件验证叠放场景。
- [ ] 退全屏保留证据、原跳转位置和返回回答的路径。全屏内可切换阅读方式，桌面宽屏保有双栏。证据定位临时提示三秒后消隐，手动滚动立即清除。
- [ ] 打开笔记抽屉和确认框时焦点进入对应控件，关闭后回到触发处。精读现有的两个阻塞确认改用可聚焦模态对话框，保留现有确认文案和业务行为，供 09 升级重新阅读。
- [ ] 折叠阅读导航分支时，离场过渡仍可见，同时该分支退出 Tab 顺序和辅助技术树。
- [ ] 工作区选择只在独立入口自动聚焦。统一设置页标题文案，清理未接入的外观保存回调。
