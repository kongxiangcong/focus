# 07: 知识库统一按精读进度显示电量和筛选

**What to build:** 读者在列表、卡片、筛选和计数看到同一个精读状态。电量表示当前 Reading Plan 的已读段数，准备失败和材料异常仍有处理入口。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Core 和 Host 投影能区分未进入精读正文、已进入但读完零段，以及已完成计划。单段文章进入正文后显示 `0/1`，为空电量但归「阅读中」。仅准备就绪仍归「未开始」。
- [ ] 列表、卡片、筛选及计数复用同一投影。保留真实历史精读进度，历史独立完成记录仍存档。有无当前计划时，独立记录均不能影响状态、电量、筛选或计数。
- [ ] 覆盖空框、低电量红色、中电量琥珀色、高电量浅绿、深绿满电。所用语义颜色符合规格，满电只在全部 Chunk 已读完时出现。可取得段数时显示已读数、总数及百分比，并提供可读的进度名称和值。
- [ ] 验收进入正文、正常推进、回看、已有计划完成和无计划来源。回看维持已读高水位，已完成来源打开后可访问全部已读正文。
