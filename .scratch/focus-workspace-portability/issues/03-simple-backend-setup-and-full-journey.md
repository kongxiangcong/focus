# 03: 简洁 Backend 初始化与设置

Status: resolved

**What to build:** 初始化和设置共用简洁的 Codex／DeepSeek 配置体验：默认即可进入，检查成功后选择真实模型，依赖按需准备，空闲时一次保存并应用。本票最后串联首次进入、使用、换库和复制恢复，完成整个需求的真实验收。

**Blocked by:** 02 — 工作区选择、切换与复制恢复。

## 实施边界

将模型偏好、连接检查、模型发现、按需依赖和配置应用作为一个完整用户流程实施；不拆成多个后台与前端票。最终串联验收是本票的完成条件，不能因取消独立验收票而省略。继续使用项目部署及项目目录 .env，不新增发行包。

## Acceptance criteria

- [x] 初始化默认 Codex 和“使用默认模型”，提供 Backend 单选、对应连接检查和模型下拉；与工作区选择共同完成一次进入，沿用 Mist 主题且不堆叠高级路径／版本／凭据表单。
- [x] 两个 Backend 分别保存默认／手选模型偏好，切回恢复选择，任一时刻只有一个生效 Backend；返回默认会清除该 Backend 的手选覆盖，默认值由 FOCUS 发布版本的 Host 规则统一解析，无需联网。
- [x] 首次检查使用默认模型执行无业务工具及私人来源的最小推理，成功后才加载该 Backend 的真实模型清单。Codex 使用选定 Runtime 清单，DeepSeek 使用供应商清单与当前调用路径可支持的模型；固定数组或另一后端缓存不得冒充真实清单。
- [x] 检查区分依赖就绪、连接通过、列表加载和当前模型已验证。改选模型不自动再次推理，可主动重检当前选择；旧模型成功不能标为新模型已验证，目录存在不能证明所有模型或全部业务已验证。
- [x] 结果绑定 Backend、实际 Runtime、认证配置版本和所检模型；切换或关闭页面后的迟到响应不覆盖新选择。手选模型被清单遗漏时保留偏好和可操作提示，不暗中改模型。
- [x] 未检查、不手选模型、检查失败或清单失败均可选择默认进入；清单失败与连接失败分别提示，可重试清单。已有文章、Blog、译文、Notes 与进度可浏览，AI 功能按实际准备／认证结果反馈，不静默换供应商。
- [x] 跳过检查及默认进入不发起安装、登录、推理或模型发现，页面挂载不暗中配置；本地读取依赖状态可以进行。检查本身不激活配置、不创建讨论或修改阅读资产。
- [x] 仅点击检查或首次显式使用 AI 时，按需准备所选 Backend 的缺失依赖，优先复用已有 Runtime；显式路径失效不偷偷换路径，安装失败可重试且不安装未选 Backend。基础 SDK／Runtime 缺失不阻止初始化页打开。
- [x] Codex 复用已有登录，未登录提供主动授权入口；选中、保存、跳过或安装依赖不触发登录，不用继承 API Key 偷换认证。密钥只由 Host 读取，错误与日志脱敏，不进入浏览器或工作区备份。
- [x] 小字统一提示“API 密钥等配置可在项目目录的 .env 文件中填写；Codex 使用已有登录。”路径及 Backend／模型选项由应用自动保存，跨工作区共用，不误称全部保存于 .env。
- [x] 设置用一次“保存并应用”公共操作完成空闲检查、保存和激活；编辑及连接检查不生效，不强制额外远端推理。有任务或执行中批次时服务端拒绝配置切换。
- [x] 保存或应用失败保留原已保存与生效配置，草稿可重试；重启不启用失败变更，未知结果通过权威状态确认。成功后各页面同步，讨论身份、Notes 和阅读前沿保持不变。
- [x] 完成本票确定性、Host 和浏览器验证：每后端偏好、切回恢复、无网络默认、跳过零动作、检查与清单失败、迟到响应、按需准备、显式登录、应用失败与忙碌竞争。
- [x] 分别使用真实 Codex、DeepSeek 留下依赖解析／实际认证状态、最小连接、真实模型清单和所选模型关键业务调用证据；既有登录复用与首次登录、替身协议测试与实际 Runtime 结果分别报告。
- [x] 在正常项目启动方式下串联三票：全新配置进入 → 新建／导入 → 默认跳过／真实检查 → 阅读与讨论、Notes、Blog／准备 → 空闲保存后端和换库 → 退出复制 → 新位置恢复并继续未完成工作。两种 Backend 的共同业务路径、两页面隔离和当前主题交互均有证据。
- [x] 最终检查确认当前无旧格式迁移、没有独立 Windows 包和无工具链启动要求；启动、项目 .env、退出后目录复制及导入恢复说明与实际行为一致。
- [x] 分层记录确定性、Host／进程、浏览器、真实 Runtime、内容与恢复的通过／失败／未测／阻塞。对既有基线失败另列身份，不以历史验收或模拟结果宣称本轮通过；所需真实场景受阻时保留证据，不将本票标记为完整完成。
