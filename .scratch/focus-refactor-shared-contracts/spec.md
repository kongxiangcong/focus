# 阅读工作台跨专题契约：证据导航、讨论边界与分批验收

Status: resolved

## Problem Statement

读者点开回答证据时，目标 PDF 页可能仍在加载。期间读者可能已经翻页、切换译文、退出全屏，甚至确认重新阅读同一篇来源。迟到的定位会把人带离刚刚选定的位置。同一段内容还可能被多个回答、多个证据编号或不同轮次的讨论引用，读者需要知道标记会把自己带回哪里。

## Solution

工作台按读者最近一次操作决定定位。成功从回答跳到来源后，保留能返回具体编号的出发位置。精读证据列表按编号计数，来源通用标记按回答提供返回入口，两者都限定在当前 FOCUS Discussion。重新阅读开启新讨论，并使旧讨论的导航立即失效。

## User Stories

1. 作为读者，我希望切换 Reading Source 后只看到新来源的内容，以便快速切篇时也能核对正确的文章。
2. 作为读者，我希望连续点击证据时跳到最后选中的一条，以便更改查证目标。
3. 作为读者，我希望在目标页加载期间仍可手动浏览，以便留在自己选择的位置。
4. 作为读者，我希望手动切视图或 Tab 能结束旧跳转，以便迟到的结果不会带走焦点或显示过时的失败提示。
5. 作为读者，我希望证据定位所需的自动切换顺利完成，以便从精读找到对话中的回答，再按编号核对来源。
6. 作为读者，我希望手动切换 PDF 和译文时优先看到对应段落，以便对照阅读。
7. 作为读者，我希望缺少段落映射时能恢复目标视图上次的位置，以便接着读；首次进入时从开头读起。
8. 作为读者，我希望退出全屏后仍能看到刚刚点选的证据，以便在窗口模式继续核对。
9. 作为读者，我希望浏览其他页再回来仍能从高亮编号返回原回答，以便接上刚才的思路。
10. 作为读者，我希望取消或失败的跳转保留最近一次成功的返回位置，以便仍能沿原路返回。
11. 作为读者，我希望确认重新阅读后清除旧讨论的导航，以便新一轮阅读从当前讨论开始。
12. 作为读者，我希望取消重读时能接着完成先前的定位，以便取消确认不会打断阅读。
13. 作为读者，我希望精读段落的证据条数与展开后的可点击条目一致，以便一次就找到想核对的编号。
14. 作为读者，我希望原文和译文只展示当前讨论的回答标记，以便点开就能找到仍在当前讨论里的回答。
15. 作为读者，我希望从通用标记找到回答正文，从高亮编号返回具体编号，以便按自己的点击目标导航。
16. 作为读者，我希望查证引文、切换视图及全屏时保持 Reading Cursor 和已读段数，以便精读进度反映实际阅读。

## Implementation Decisions

- 工作台统一持有当前来源、递增的切换代际及单一 SSE 快照。文档、PDF、概览、精读与证据回调落地前核对来源和代际，即使从 A 切到 B 再回到 A，第一轮 A 的结果也应失效。
- 跨 Tab 跳转携带来源、回答、证据、首选视图和一次性标识。滚动、报错及清除意图前均核对当前标识。成功命中或完成降级后立即消费。滚轮、触屏、滚动条、键盘主动浏览，以及手动切视图或 Tab 均取消等待中的定位。流程发起的切换与滚动可继续。
- 手动切换 PDF 与译文时，有可靠对应关系则同步；否则恢复本次打开该来源后目标视图上次停留的位置，首次进入从开头展示。点击证据另按证据规则处理：PDF 优先用全部可靠框，其次用可靠页码；无可靠位置或版面失配时转译文。译文缺少可靠关联时保留当前位置并展示签发的原文引文。
- 单独退出全屏保留意图，目标就绪后按当前布局定位。成功从回答跳到来源后保存回答和编号的返回位置。本次打开来源期间，手动浏览、切视图、切 Tab、退出全屏均保留该关系。下一次从回答成功定位到来源时替换，取消或失败时沿用旧值。
- 确认重新阅读立即清除旧讨论的待处理跳转和返回位置，即使来源相同也隔离迟到的旧回调。取消确认保留原状。旧讨论随原有归档保留。精读推进、ADR 0035 定义的末段完成与确认重读拥有修改进度的权限。
- 每个 Chunk 以当前块集合与已验证证据块的交集筛选当前讨论证据，再按回答与证据编号去重。零条时隐藏胶囊，条数等于展开后的证据项数。点选条目先定位到回答中的编号，再由读者点击编号进入来源。
- 原文和译文的通用标记按当前讨论中关联的不同回答数展示。零条隐藏，一条直达回答正文，多条列出回答摘录供选择。同一回答的多个编号引用该块时均可在正文点选。从具体编号跳来时，点击对应的高亮编号直接返回该编号。
- Batch A 可交付工作台运行时与主题底座。专题 01 的 Batch C 以真实 PDF 的 Batch B 验收通过为前提。专题 02 的完成、重读与知识库电量在自身前置工作就绪后独立实现和验收。专题 01、02 界面均定型后，专题 03 进行五套主题的组件对比度、代表页面截图与系统主题切换终验。

## Testing Decisions

使用已确认的正式 Host 浏览器阅读流程作为主入口。复用阅读矩阵、讨论、抽屉与译文、精读完成的浏览器用例，以及专题 01 的真实 PDF 样本。通过现有 HTTP/Core 接口读取持久化的精读进度和讨论，用读者可见的视图、落点、引文、提示与保存结果判断通过。延迟目标页或旧响应，按明确顺序释放，避免依靠偶然的网络时序。

| 场景 | 可观察的通过条件 |
| --- | --- |
| 切篇与连续点击 | A→B→A 后释放第一轮 A 的响应，当前文章与位置保持正确。连续选 ③、④，分别迟到返回 ③ 的成功和失败，④ 的落点和提示保持正确。 |
| 用户取消与程序切换 | 分别在等待中手动滚动、切译文、切 Tab，再释放结果，界面停在读者选择处。精读自动切到回答、无可靠 PDF 位置时自动转译文均可完成。 |
| 双向切换 | PDF 与译文两个方向各测可靠映射、缺映射且访问过目标视图、缺映射且首次访问，分别命中对应内容、上次位置和开头。 |
| 退出全屏 | 延迟 PDF 目标页，退出全屏后释放，证据在新布局中可见；另一次退出后先主动滚动再释放，停在手动位置。 |
| 保留与替换返回位置 | 从 B·④ 成功定位，翻页、切视图或 Tab 后回来仍能返回 B·④。随后分别取消、失败一次，旧返回仍有效；成功从 C 定位后返回 C 的编号。 |
| 同来源重读 | 旧定位等待时取消重读，原跳转可完成。重复操作并确认重读，迟到回调不能滚动、报错或恢复旧返回位置。新讨论为空，旧回答和引文在归档中保留。 |
| 胶囊与两视图标记 | 旧讨论的 A 引用表格，新讨论起初无标记或胶囊。新回答 B 的 ③ 命中两个块、④ 命中其中之一，该 Chunk 显示 2 条，分别落到 B·③、B·④。在 PDF 和译文点表格的通用标记均直达 B 正文。从 B·④ 跳来点高亮 ④ 精确返回。新增 C 引用后选择列表仅含 B、C。 |
| 精读进度与界面终验 | 对比导航、重连及全屏前后的 Reading Cursor 和已读段数。复用正式 Host 的尺寸、主题与低动态浏览器矩阵，在最终界面核对证据高亮、错误条及知识库电量在四套浅色和一套深色主题中的可辨性。 |

## Out of Scope

解析格式、证据签发算法及旧 Bundle 兼容沿用专题 01；精读完成与数据恢复沿用专题 02 和 ADR 0035；具体配色、布局及动效沿用专题 03。本规格覆盖它们在同一工作台中的交互与验收依赖。实施工单另行拆分。
