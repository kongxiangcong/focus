# 04: 精读段落按当前讨论的证据编号计数

Status: resolved
Blocked by: None (can start immediately)

**What to build:** 读者从 Chunk 展开证据胶囊，看到当前讨论里引用该段的每个编号，并可逐项核对。

- [x] 同一 Chunk 内，B·③ 命中两个已验证块，B·④ 命中其中一个。胶囊显示「对话证据 · 2 条」，展开后两个编号各占一项。
- [x] 点选任一项先到 B 正文里的对应编号；再次点编号才定位到来源。未命中该 Chunk 的条目不进入列表。
- [x] 用已有重读入口开启新讨论，确认旧回答仍在归档，新一轮起初无胶囊。新讨论首次用一条证据引用该段后，显示 1 条并定位到新回答。
- [x] 在正式 Host 的浏览器阅读入口完成上述操作，通过现有 HTTP/Core 接口核对导航前后的 Reading Cursor 与已读段数保持一致。

## Comments

真实 PDF 的 L127 让 B·③ 同时关联两个已验证块，B·④ 只关联其中一个。胶囊显示两项，逐项先到回答编号，再由编号进入来源。重读后旧回答仍可查看，当前讨论从零项起步，不同回答的同号各自计数。公开接口确认导航前后的进度一致。 [浏览器用例](../../../tests/chunk_discussion_evidence_browser.mjs)
