# 05: 确认重新阅读时隔离旧讨论的导航

Status: resolved
Blocked by: 01, 03

**What to build:** 在同一 Reading Source 确认重新阅读时开启新的讨论边界，读者可以在取消确认后接着查证旧讨论。

- [x] 在正式 Host 的浏览器阅读入口，从旧讨论的回答成功定位，留下返回位置，再发起一次延迟加载的定位。确认重新阅读后，旧跳转和返回位置立即失效。
- [x] 在新讨论中分别释放旧请求的成功与失败，均不会滚动界面、显示过时提示或恢复旧返回位置。旧回答及引文仍可在归档中核对。
- [x] 在相同初始状态取消重读，原返回位置仍有效，待处理跳转仍可完成。通过公开接口核对取消后讨论、Reading Cursor 和已读段数保持原值；确认后读取的是新轮次进度。

## Comments

正式 Host 保持重读请求等待，以迟到的 PDF 成功和失败分别验证确认前后的边界。取消后原定位完成且 Discussion、Reading Cursor 与已读段数保留。确认立即清除旧导航，新讨论从零段起步，旧回答和引文可在归档核对。 [浏览器用例](../../../tests/evidence_navigation_browser.mjs)
