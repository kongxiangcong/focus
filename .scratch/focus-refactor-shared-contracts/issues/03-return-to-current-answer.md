# 03: 从来源标记返回当前讨论的回答或编号

Status: resolved
Blocked by: None (can start immediately)

**What to build:** 同一来源块可关联多个回答和编号。通用标记帮助选择回答，从回答跳来时高亮编号可带读者精确返回。

- [x] 在 PDF 和译文分别验证：仅归档讨论引用时隐藏标记；当前回答 B 的 ③ 和 ④ 同时引用时，通用标记直达 B 正文，两编号均可点选；新增 C 引用时仅列出 B、C 的摘录供选择。
- [x] 从 B·④ 跳到来源，手动翻页、切视图、切 Tab 或退出全屏再回来，点击高亮 ④ 仍精确返回 B·④。
- [x] 分别取消另一次跳转、让另一次跳转失败，验证原编号仍返回 B·④。从 C 的编号成功定位后，再点对应高亮编号应返回 C 的出发位置。
- [x] 在正式 Host 的浏览器阅读入口完成上述操作，通过现有 HTTP/Core 接口核对导航前后的 Reading Cursor 与已读段数保持一致。

## Comments

真实 PDF 和译文的通用标记在单回答时直达正文，多回答时只列出当前讨论的 B 和 C。已验证 B·④ 的编号返回可跨翻页、视图、Tab 和全屏保留，取消与失败沿用旧位置，C 成功定位后替换。公开接口确认精读进度一致。 [浏览器用例](../../../tests/current_discussion_evidence_browser.mjs)
