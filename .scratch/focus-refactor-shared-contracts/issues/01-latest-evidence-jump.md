# 01: 让待处理的证据跳转服从最近一次操作

Status: resolved
Blocked by: None (can start immediately)

**What to build:** 读者可以改变目标或继续浏览。只要读者仍在等待，目标就绪后就在当前布局完成定位。

- [x] 依次打开 A、B、A 后释放第一轮 A 的文档、PDF 或概览响应，当前来源与位置保持正确。连续点击 ③、④，分别迟到返回 ③ 的成功与失败，④ 的定位和提示保持正确。
- [x] 分别在目标页加载期间使用滚轮、触屏、滚动条、键盘，或手动切视图、切 Tab。随后释放旧响应，界面停在读者选择处，无过时提示。
- [x] 从精读点证据能自动切到回答；从回答点编号时，可靠框、仅有页码、版面失配分别命中 PDF 块、PDF 页、译文。有意图的程序滚动能完成，完成后的重放不会再触发定位。
- [x] 等待期间仅退出全屏时，在窗口布局中命中证据；若退出后主动滚动，再释放目标页，阅读位置停在手动选择处。
- [x] 在正式 Host 的浏览器阅读入口完成上述操作，通过现有 HTTP/Core 接口核对导航前后的 Reading Cursor 与已读段数保持一致。

## Comments

正式 Host 在旋转件和原件上验证 A→B→A、③ 和 ④ 的迟到响应、滚动手势、视图切换和全屏。复核另覆盖对话滚动条、退出时正在滚动的跳转、PDF 重试，以及页级和译块降级。HTTP 快照中的 Reading Cursor 和已读段数一致。 [浏览器用例](../../../tests/evidence_navigation_browser.mjs)
