# 06: 验收最终阅读界面的五套主题

Status: resolved
Blocked by: 01, 02, 03, 04, 05

**What to build:** 在阅读界面定型后，读者能在四套浅色主题与炭灰深色主题中辨认证据、错误和知识库电量。外部前提为专题 03 的五套主题已可在正式 Host 验收。

- [x] 在正式 Host 的蓝、绿、红、黑白四套浅色与炭灰深色主题中检查实际组件对比度，覆盖证据高亮、错误提示、电量、按钮文字、悬停、激活和键盘焦点。
- [x] 代表页面保留截图，在 720、1024、1440 像素及触屏、低动态模式下复验布局、可见性与证据定位。通过现有接口对比导航、全屏及 SSE 重连前后的 Reading Cursor 和已读段数。
- [x] 跟随系统从浅色切深色再切回，恢复原选浅色配色。记录各组合的结果与截图，关联专题 01 既有真实 PDF 验收记录。

## Comments

五套主题在 25 个正式 Host Chromium 组合中通过。另验证五套主题中 50% 电量的默认、悬停和激活态，四套浅色配色各自经过系统深色切换后恢复。记录包含 14 张截图、实际组件对比度及导航、全屏和 SSE 重连期间的进度快照。 [验收记录和截图](../theme-acceptance/README.md)
