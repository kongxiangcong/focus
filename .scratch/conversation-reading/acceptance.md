## 修正与保留的问题

- 修正初始导读加载使右侧自动滚到底部的问题。
- 修正快速切换场景时初始延迟开场可能覆盖新场景/问题的问题。
- 调整双栏最大宽度，防止中等宽度拉动分隔条后挤出视口。
- 为窄屏隐藏文字的目录/笔记按钮补可访问名称。
- 浮卡改用可逆 opacity/transform transition，关闭即禁用交互，减少动效不位移。
- 开发中曾观察到两条 React createRoot 的热更新重复挂载告警；加入 HMR dispose 后重新加载与后续验证未出现新的同类错误。不能据此声明所有浏览器均无错误。
- 浏览器等待一次使用了默认短期限，在模拟分段回答完成前超时；随后核对已完成状态并继续测试，非回答逻辑失败。之后等待明确设置合理超时。

## 原型与生产要求的差异

- 文本与回答均为合成演示，固定 evidence → DOM ID 映射；真实引文校验、解析树映射、重复引文消歧、跨版本查阅、SSE 乱序/重连/模型停止恢复未实现。
- 模拟按段增量显示，不模拟真正 token SSE。没有模型、自动准备 worker 或真实 web 搜索。
- 首次提问会将开场收成一行，随时可展开；该交互供本次评审确认。
- 笔记/读完/草稿仅保存在内存。没有持久书签、新旧 Cursor 迁移、事务清除、生产权限或完成状态写入。
- 原文公式展示存在，但没有单独的公式引用场景；图表覆盖当前对象高亮体验。
- 已有用户重点通过单独样式示例呈现，未实现真正重叠 range 的冲突合成。选择文字提问有原型实现，未完成跨块/触摸/IME 的全面浏览器验收。
- 笔记面板、场景控制与快捷输入为原型用途；面板退出动效、真实笔记编辑、图片加载锚点保持、长文虚拟化与性能需正式实现。
- 未测试 200% 缩放、屏幕阅读器、真实移动设备、全部浏览器、长文性能或旧知识库副本。规格中的完整生产矩阵由工单 09 执行。
- 原型未调用正式 ReaderHost/后端，不意味着唯一入口改造已经正式上线。
