# 03: 完成后端续接与真实运行验证

What to build: 入库失败沿当前有效进展继续，取消后迟到结果不能发布；在共享后端中实际接通 MinerU 与参考 Codex，以有限且直接的场景证明成功和关键失败恢复。

Blocked by: 02 — 完成共享后端入库主流程

Status: ready-for-agent

- [ ] 一旦取得远端任务引用即持久化非秘密恢复信息。超时或重启先查询／恢复原任务；已有有效解析结果或已发布 Source 不重做。受理不明且查询无法定位时返回状态待核对，不自动重新上传。
- [ ] 从已确认输入、远端任务、可用结果、待发布候选或待补 Topic 关联恢复；提交成功但响应丢失也识别已有结果。关联失败的续接只补关联，不改 Bundle。
- [ ] 暂时性网络错误最多自动续接两次，再等待手动重试；认证及校验失败直接报告。相同输入、服务和范围沿用原确认，改变范围重新确认；轮询不算重新执行。
- [ ] 取消先禁止旧 attempt 提交再请求外部停止，保留合法已完成产物；迟到结果被拒绝。明确继续使用新 attempt，从最后有效断点执行，业务状态如实反映远端尚未停止的情况。
- [ ] 以少量真实持久化／进程案例验证重启后的幂等、冲突和独占写入；复用 02 的提交约束，不另造一套状态或防御框架。
- [ ] 将 MinerU、参考 Codex 接入同一 Application；必要 AI 步骤受限，模型不直接改正式资产。实际验证认证、任务所需模型／图像能力、结果校验和取消；凭据只在适配器内，缺少能力明确报告，不静默切换服务或 fixture。
- [ ] 使用已授权 PDF 和隔离目录完成真实后端入库，抽查核心图表、公式、阅读顺序。再次添加同一已入库文档验证复用，不为验收重复解析已有 Source；记录真实结果与未通过项，不以历史 Parser 成功替代本轮工作流成功。
- [ ] 合并更新被新工作流替代的测试和技能约束，记录有效失败，不恢复 CodeBuddy 测试。只保留有实际行为价值的回归，不新增独立防御性测试工程。

Verification: Application 主边界上的可控外部故障验证，与一个授权样例的真实服务验证并列记录。真实外部故障不可稳定制造时，用可控适配器证明确定性语义，并明确真实证据边界；必要能力未通过时，本票不能标为完整完成。

Spec coverage: T09–T18，T19–T20 的重启／进程边界，T23 的真实适配器凭据边界；真实 Parser／Runtime 与内容抽查门槛。无需前端改造。
