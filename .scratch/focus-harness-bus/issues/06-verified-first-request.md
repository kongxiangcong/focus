# 06: 检测回执与首次发送

**What to build:** 复用实际执行配置的成功回执，让首次发送在通过验证后自动继续。

**Blocked by:** 01 用标准 Manifest 运行现有 Codex、02 用临时来源替换文本探针

**Status:** ready-for-agent

- [ ] 回执绑定 Backend ID、解析后的可执行路径、实际模型及有序命令参数。逐项修改验证失效；相同配置复用通过回执。
- [ ] 旧文本记录按未验证处理；无需迁移旧回执。首次使用时显示「正在检测 Backend」。
- [ ] 从发送入口检查负载和顺序：探针通过后原请求执行一次；失败保留输入并提示原因，用户文章与问题均未发往候选 Backend。
