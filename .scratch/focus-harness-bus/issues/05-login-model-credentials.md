# 05: 按能力提供登录、模型和凭据配置

**What to build:** 设置页根据条目能力提供登录和模型选择，子进程获得该条目声明需要的环境。

**Blocked by:** 01 用标准 Manifest 运行现有 Codex

**Status:** ready-for-agent

- [ ] 默认 Codex 能主动发起及取消登录，沿用 ChatGPT 登录态并隔离冲突 API key；外部登录条目显示对应指引。
- [ ] 支持发现的条目可加载模型清单，失败可重试；允许手动输入，清单加载成功不会将清单内模型标为检测通过。
- [ ] 沿用 credentialFile 路径，按 Manifest 声明读取所需变量并注入独立子进程环境；缺文件或键时给修正指引。验证密钥值不进入设置、Manifest、回执或错误显示。
- [ ] 登录和模型操作经统一驱动接口，服务、设置和探测控制面无提供方专属分支。
