# 07: 多页面安全地保存并应用

**What to build:** 多页面在同一 Host 上保存并应用时，所有页面得到一致的生效配置。

**Blocked by:** 06 检测回执与首次发送

**Status:** resolved

- [x] 从检测前到提交或失败独占切换权；优先使用匹配成功回执。期间可浏览，新 AI 任务和并发应用收到可重试提示。
- [x] 已有前台任务时拒绝切换；仅有后台预生成摘要时取消预生成并拒收迟到结果。
- [x] 覆盖探针失败及写盘失败，原保存值及生效值均保留；应用成功后各页面同步，讨论、阅读位置、笔记和已有证据仍可访问。
