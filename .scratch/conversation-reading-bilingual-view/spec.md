# 双语对话阅读、跨段笔记与阅读版本

Status: resolved

## Problem Statement

读者想在中文里读论文，看见回答中的引用时，一次就能回到相应段落，并在需要时核对原文。现有 PDF 画布、证据浮卡和分开的准备状态，使读者需要在不同界面间寻找同一处内容。在对话正文选文记下的想法，也难以在逐段精读的对应小段找回。

读者还需要带着新问题从头读同一篇论文。现有重读流程可以存档对话，但仅靠旧对话无法恢复当时的译文、小段边界、批注和阅读进度，也无法在旧轮次继续读写。

## Solution

一次上传完成本轮阅读所需的全部准备，再同时开放「逐段精读」和「对话」。两种方式共用本轮的译文和小段笔记。对话阅读显示可切换语言的单栏正文，回答编号直接定位证据，侧栏目录负责跳节，「打开原件」用于核对原始版面。

确认「重新阅读」时，先把当前选中轮次的完整阅读状态做结构化备份，再创建新一轮。每轮只保留最近一次成功备份及其时间。读者可在论文管理切回任一已就绪轮次，接着读、记笔记或在原对话里追问。

## User Stories

1. 作为上传者，我希望一次上传 PDF、HTML 或 Markdown 就启动整篇准备，以便直接获得可读的正文、计划和全部小段。
2. 作为读者，我希望两种阅读方式一起就绪，以便打开对话正文时就能在精读中找到对应小段。
3. 作为读者，我希望准备中能看到状态，失败后可以重试，以便继续完成本轮准备。
4. 作为历史来源的读者，我希望复用已有的可用内容、补齐缺失项，以便继续阅读旧资料。
5. 作为外文论文读者，我希望首次打开默认中文，再次打开恢复本篇手动选择的语言，以便直接沿用习惯的视图。
6. 作为中文文章读者，我希望直接看到原文，以便省去多余的语言选择。
7. 作为读者，我希望图表、公式、附录和参考文献出现在正文原有位置，以便连贯阅读全文。
8. 作为双语读者，我希望切换语言后停在眼前的小段，以便就地对照措辞。
9. 作为核对回答的读者，我希望点击编号就能看到出处及前后文，以便判断原文是否支持回答。
10. 作为读者，我希望原文可精确定位时看到逐字引文，复杂表格或公式则显示可验证的块，以便了解证据的准确范围。
11. 作为中文视图读者，我希望在对应译段看到同一条证据，切回原文仍能核对原句，以便分清论文原话和译法。
12. 作为旧资料读者，我希望遇到不可靠的译段对应时能看到可验证的段组或原文，以便避免被错误高亮误导。
13. 作为读者，我希望正文证据编号能带我回到发起引用的具体回答并恢复焦点，以便接着阅读那条回答。
14. 作为读者，我希望连续点引用后就停在最后一处，以便从那里接着读。
15. 作为精读读者，我希望查看证据、切语言或用目录浏览时保持精读进度，以便回来时仍从本轮实际读到的小段继续。
16. 作为长文读者，我希望目录按真实标题层级展示并标明当前小节，以便知道自己读到了哪里。
17. 作为键盘用户，我希望能分别展开目录分支、跳到标题和激活证据编号，以便独立完成导航。
18. 作为手机读者，我希望目录按需展开，选择标题后能看到正文，也能从正文返回对话，以便在窄屏上阅读。
19. 作为核对版面的读者，我希望「打开原件」能打开当前所读页，以便查看对应的 PDF 表格或公式。
20. 作为笔记作者，我希望在对话正文选文后直接记一条小段笔记，以便在对应精读小段找到它。
21. 作为笔记作者，我希望跨两个小段选文也只写一次，以便两段都能看到同一条完整笔记，面板只列一条。
22. 作为双语读者，我希望中英文都能读到该笔记，而只有实际选过的字被高亮，以便准确找回自己的选文。
23. 作为笔记作者，我希望保存后自动高亮、取消草稿时正文保持原样，以便由保存动作确定是否留下标记。
24. 作为笔记作者，我希望在任一小段编辑或删除笔记时各处一起更新，单独画过的重点仍可保留，以便只管理一条笔记。
25. 作为读者，我希望能直接从面板写整篇笔记，以便保存独立于具体小段的判断。
26. 作为重读者，我希望确认重读前了解备份和继承规则，以便决定开始新一轮或取消。
27. 作为重读者，我希望系统先备份译文、进度、批注和带引用的对话，以便完整找回当时的阅读状态。
28. 作为重读者，我希望新一轮重新规划、切段和翻译，从第一段和空白讨论开始，以便形成独立的阅读记录。
29. 作为笔记作者，我希望新一轮带入整篇笔记的独立副本，以便更新今天的判断，同时留住上一轮的原句。
30. 作为读者，我希望在论文管理一眼识别当前轮次并切换整套状态，以便恢复对应译文、笔记、书签和对话。
31. 作为重读者，我希望回到旧轮后能继续读、编辑并追问，以便随时续接那一轮的思路。
32. 作为重读者，我希望能从旧轮次的最新内容发起第三轮，以便沿用选中轮次的整篇笔记，并保留中间各轮。
33. 作为读者，我希望论文管理每轮只列一项，只保留该轮最新备份及时间，以便直接按轮次切换。
34. 作为遇到中断的读者，我希望失败后仍能打开最近的成功备份，重试只创建一轮，以便安全恢复。

## Implementation Decisions

- **统一阅读准备。** 对同一 Reading Source 的同一 Reading Version，Source Document、适用的完整中文译文及原文映射、Reading Plan 和全部 Reading Chunk 均就绪后，同时开放两个入口。中文来源省去翻译。准备期间或失败时在入口显示状态或重试。准备就绪与精读已开始分别记录。
- **正文与翻译。** ReadingDocument 向两种阅读方式提供有序原文块、原文范围、章节层级、可选页码和本轮译文映射。复用 Source IR，译段可覆盖一组原文块。将译文和已校验的映射一并发布，按阅读版本保存，可独立于精读小段的拼接方式读取。每轮只有一份当前译文，普通打开及切换版本使用已保存内容。重译已有完整译文只由重新阅读触发。
- **单栏与原件。** PDF、HTML、Markdown 共用正文排版、字号、主题、选文和批注交互。宽表、代码、公式在块内横向滚动。原件可用时工具栏提供唯一的「打开原件 ↗」。PDF 按当前阅读位置的可靠页码打开，页码未知时打开文件，HTML 按原件地址打开。移除对话正文的内嵌 PDF 画布、红框、坐标反推、远端页等待、证据浮卡及其专属样式，清理 PDF.js 依赖和静态资源拷贝。
- **双语位置与证据。** 外文控件使用「中文｜原文」。切换语言时，活动证据仍在视野内则保留其高亮；读者已经滚远则以当前段落为准。Answer Evidence 始终由原文逐字引文及唯一范围签发，绑定来源、Parser Bundle 版本、具体回答修订和原文位置。中文视图只投影到可靠对应的译段。旧 Bundle 只读兼容，无 Source IR 时用规范 Markdown 和原文行范围。映射只能验证到段组时高亮段组，无法验证段组时原位显示可验证的原文块。相同段数不足以证明对应。解析版本不符、缺少范围或引文歧义时沿用证据校验规则。
- **引用导航。** 一次激活只定位和高亮。目标已完整可见时就地高亮，跨屏时留下前后文。桌面保留两栏，手机切到正文，沿用「查看正文」「返回对话」。正文编号回到所选回答的具体引用并恢复焦点；同处被多次引用时采用当前所选回答的编号。连续跳转停在最后成功的位置，省去返回原阅读位置的动作。临时高亮与批注重叠时保留批注样式，段侧标示证据。保留精读段底已有的对话证据入口。手动滚动、键盘翻页和目录跳节更新 Reading View Bookmark。证据跳转、切语言及浏览动作均不推进 Reading Cursor。
- **侧栏目录。** 使用真实标题与起始块构建层级。保留已有章号，缺号按层级补全。中文标题有可靠映射时随语言切换，其余使用原题。整体与各分支分别开合，箭头只控制子项，点标题只跳节。跟踪当前位置，分支已收起则选中最近可见父节；引用跨节和切换语言保留读者的展开选择。宽屏默认展示，窄屏默认收起，手机点标题后收起。无标题时省去空目录，文章导读保留概览。
- **笔记身份与高亮。** 从选文创建的 Reading Note 是一条小段笔记，保存选文位置和覆盖的小段。两个入口、两种语言和所有关联小段共享该轮同一条笔记。每段只在选文语言高亮本段所选部分。持久化成功后再产生笔记高亮，取消草稿不新增标记。删除同步移除这条笔记及其自动高亮，保留读者单独标过的 Reading Highlight。无正文位置的面板笔记归入整篇笔记，句子备注沿用其原有定位。
- **结构化备份。** 在已确认的重新阅读操作中，按来源、选中阅读版本和解析版本保存一致的可恢复状态：计划、小段、Reading Cursor、进度、书签；译文、原文映射、结构与导读；各类笔记、重点、选文与跨段关联；该轮可见对话、消息修订、摘要、回答证据与引用关系。先验证完整可读，再以新备份及成功时间一起替换该轮原有备份。备份失败时当前阅读状态、之前的备份和时间均保留。
- **创建新一轮。** 只有备份成功后才按本篇创建顺序追加一个 Reading Version。从所选轮复制整篇笔记，重新规划、切段、翻译。已读段数归零，从新计划第一段开始。小段笔记、句子备注、重点和对话从空开始，旧轮消息与摘要留在原轮。新一轮准备失败时可重试，旧轮仍可从论文管理选取。沿用可恢复重置及旧写入隔离，重试同一操作只追加一个新轮次。
- **版本切换与兼容。** 论文管理按创建顺序平铺轮次，每轮一项，标识当前轮及最近一次成功备份时间。切换恢复该轮最近保存的整套阅读状态。进度、注释及讨论写回操作所属轮次，迟到的旧操作不得改写当前显示的另一轮。切换本身不重译或重新规划。保留来自旧 Host、旧 Bundle 和既有计划的可用内容；同一解析版本下，重切小段后旧回答仍可定位原文，并可按当前展示的可靠映射找到译段。

## Testing Decisions

用户确认两个测试入口。以正式工作台和真实 Host 的用户流程为主，用已有的公共 Host 重置测试补充浏览器难以稳定制造的故障。优先断言读者看到的文字、位置、焦点、进度和重新打开后的内容。备份验收通过公共接口恢复阅读状态来核对关联，存储格式和组件内部状态留给实现决定。

| 入口 | 操作与可观察结果 |
|---|---|
| 工作台 · 上传与准备 | 分别上传外文 PDF、HTML、Markdown 和中文来源。在仅原文就绪、译文已好但尚缺小段时，两种入口都显示准备状态。全部就绪后均可进入。验证首开语言、手动选择后重开、中文无切换控件、准备失败后重试。 |
| 工作台 · 双语与证据 | 用鼠标和键盘激活同一段被两个回答引用的编号。核对完整可见时就地高亮，跨节时保留上下文，原文可验证逐字引文，译文高亮正确段组；激活正文编号回到对应回答和焦点。连续跳转无浮卡、选择器或「回到刚才位置」。检查滚远后切语言仍在眼前段落，精读进度保持原值。 |
| 工作台 · 旧资料与原件 | 覆盖无 IR、段数相同但映射未验证、只有段组映射、复杂公式及解析版本不符。分别核对保守定位或原文回退。定位第 8 页后打开原件直达第 8 页；滚至第 12 页后同一入口打开第 12 页。页码未知也能打开文件。 |
| 工作台 · 布局与目录 | 在 1440px 和 390px 检查正文、对话、目录、图表、公式、附录与参考文献。验证无页面级横向溢出、多级标题无重复编号、键盘独立开合和跳节、折叠分支的父节选中态、手机选节后收起、无标题时省略目录。核对发布构建已移除 PDF.js 资产。 |
| 工作台 · 跨段笔记 | 同一自然段切为 c0、c1，在中文从 c0 末尾选到 c1 开头并保存。两段显示同一条完整笔记，各自只高亮所选部分，面板只列一次。切至原文在对应小段看到笔记；切回中文恢复准确高亮。在 c0 编辑、c1 删除，核对两种入口同步更新。另测取消草稿，以及先单独标重点再删除笔记后该重点仍在。 |
| 工作台 · 版本往返 | 第一轮保存整篇笔记、跨段笔记、重点和有引用的回答，并记下精读位置和书签。重读产生第二轮，核对首段、零进度、新对话、新译文与小段。第二轮把整篇笔记改成「已复现」；回到第一轮仍见原句，并可从原位置继续和在原对话追问。再次打开两轮，核对译文、引用、进度、笔记与对话各自可用。 |
| 工作台 · 三轮与覆盖 | 周一从第一轮创建第二轮，周五切回第一轮补写整篇笔记并创建第三轮。列表按一、二、三轮显示，第一轮仅保留周五的成功备份和时间，第三轮带入周五的整篇笔记，第二轮仍可独立续读。 |
| 公共 Host · 失败和重试 | 对已有成功备份的轮次制造备份中断。重新打开后原阅读状态、旧备份内容和成功时间均可核对；重试同一请求只追加一轮。另在备份成功后使新一轮准备失败，验证两入口等待重试，旧轮可切回；延迟返回的翻译、对话或笔记写入不会落入另一轮。 |

沿用现有证据导航浏览器验收中对焦点和精读进度的核对、阅读批注的双语选文样例、知识库管理的窄屏交互，以及公共 Host 重置测试的隔离工作区、失败生成和延迟返回场景。旧验收中针对内嵌画布、浮卡和单段归属的断言按本规格更新。

## Out of Scope

独立重译入口、译本管理器、同一轮的多时间点备份、阅读分支树及版本合并均在本次范围之外。全文选文沿用「记笔记」，跨小段无需新增「引用」步骤。原件通过独立入口打开，对话正文省去内嵌 PDF 画布。全局主题、入库身份规则和精读推进语义沿用现有决定。
