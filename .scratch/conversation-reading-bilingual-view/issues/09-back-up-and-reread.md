# 09: 重读前备份，安全创建新一轮

Status: resolved

**What to build:** 确认重新阅读时先完整备份选中轮次，备份可恢复后才开启新轮；新轮取得整篇笔记的独立副本，从空白讨论和全新精读开始。

**Blocked by:** [02 一次上传，完整准备后开放阅读](02-unified-preparation.md)、[07 跨小段保存一条笔记](07-shared-chunk-note.md)

[父规格 · 用户故事 26–29、34](../spec.md#user-stories)

- [x] 工作台确认前说明备份、切回与整篇笔记继承规则。取消后原轮进度、内容和对话保持原状。
- [x] 从公共 Host 恢复备份，核对来源、阅读版本、解析版本、计划、小段、精读位置、进度、书签、结构与导读、译文及映射与重读前一致。
- [x] 恢复时核对整篇笔记、小段笔记、句子备注、重点、选文和跨段关系；同一笔记在两个原小段仍为一条。讨论、摘要、消息修订、回答证据及其原文定位关系完整。
- [x] 备份成功后才新建一轮。重新规划、切段，对外文重新翻译，已读归零，就绪后从首段进入。新轮保留整篇笔记的独立副本，局部笔记、重点及对话从空开始；旧轮消息与摘要不进入新讨论上下文。
- [x] 用既有公共 Host 重置测试中断备份，重新打开后原状态完整；重试同一操作只追加一轮。另使新轮准备失败，核对可重试、两个入口仍等待本轮准备且已成功备份可恢复。
