# 07: 跨小段保存一条笔记

Status: ready-for-agent

**What to build:** 对话正文选文点「记笔记」即保存到对应小段。在逐段精读中，每个被选文覆盖的小段都能查看、编辑这条笔记。

**Blocked by:** [01 单栏原文与打开原件](01-single-column-source.md)

[父规格 · 用户故事 20、21、23–25](../spec.md#user-stories)

- [ ] 从已准备来源的原文 c0 末尾选至 c1 开头，直接记笔记。保存后两段出现同一条完整笔记，笔记面板只列一次，各段自动高亮本段选中的文字。单段选文也沿用同一动作。
- [ ] 在精读 c0 编辑后，从 c1 和对话阅读可见修改。在 c1 删除一次，两段和对话区的笔记及该笔记自动产生的高亮一起消失。
- [ ] 取消未保存草稿时不新增笔记或高亮；先单独标重点再记笔记，删除笔记后原有重点保留。
- [ ] 直接在面板新建且未关联正文的笔记归入整篇笔记。原有句子备注仍可按其定位查看。
