# 06: 可折叠的章节目录

Status: ready-for-agent

**What to build:** 读者在侧栏查看正文层级，折叠目录或分支，点击标题跳到实际小节。

**Blocked by:** [03 双语切换与位置恢复](03-bilingual-position.md)

[父规格 · 用户故事 15–18](../spec.md#user-stories)

- [ ] 使用带编号、未编号、无标题三种材料。已有章节号只显示一次，缺号按层级补全，无标题时省去空目录。中文视图优先显示可靠对应的中文标题，其余沿用原题。
- [ ] 点击标题跳到真实起始块并更新书签，箭头只控制子项。键盘可操作整体和分支。开合目录时正文停在原位，文章导读保留概览。
- [ ] 滚动、跨节定位或切语言后，当前小节更新选中态；若父节收起则标记最近可见父节，保留手动展开选择。目录浏览不推进精读。
- [ ] 在 1440px 验证默认展开，在 390px 验证默认收起且入口可达。手机选标题后目录收起，目标小节可见。
