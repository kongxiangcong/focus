# 01: 单栏原文与打开原件

Status: ready-for-agent

**What to build:** 读者在对话区用同一套单栏排版阅读已准备好的 PDF、HTML 和 Markdown，核对版面时从当前阅读位置打开原件。

**Blocked by:** None (can start immediately)

[父规格 · 用户故事 7、19](../spec.md#user-stories)

- [ ] 在正式工作台依次打开三种格式，标题、正文、图表、公式、附录与参考文献依原文顺序出现。字号和主题适用于三种格式。
- [ ] 在 1440px 和 390px 下都能阅读和选文。宽表、代码和公式在块内滚动，页面宽度保持在视口内。
- [ ] 有原件时工具栏只有一处「打开原件 ↗」。在可靠页码第 8 页打开直达第 8 页，手动读到第 12 页后再打开直达第 12 页。
- [ ] PDF 页码未知时打开文件，HTML 原件按自身地址打开。缺少原件时隐藏该动作。
