# 10: 在论文管理切换版本并继续读写

Status: ready-for-agent

**What to build:** 在论文管理选择任一已就绪轮次，整套阅读状态跟随切换。回到旧轮后，可继续精读、编辑并续接原有对话。

**Blocked by:** [09 重读前备份，安全创建新一轮](09-back-up-and-reread.md)

[父规格 · 用户故事 27、29–31、33、34](../spec.md#user-stories)

- [ ] 工作台每轮列一项，按创建顺序平铺，标明选中轮次及已有备份的最近成功时间。切换使用所选轮已保存的内容，不触发重译或重新规划。
- [ ] 第一轮带有跨段笔记、重点、原文引用及书签。切回后恢复其译文、原小段、精读位置、笔记与对话；同一解析版本下旧回答仍可定位原文，按当前可靠映射可找到对应译段。
- [ ] 在第二轮修改继承的整篇笔记，切回第一轮仍是原句。在第一轮继续读一段并在原对话追问，往返切换并重新打开后，两轮各自恢复最近保存的状态。
- [ ] 新轮准备失败时仍可从论文管理切回已就绪的旧轮。用公共 Host 延迟返回翻译、笔记写入或对话结果，再切换轮次，核对迟到操作不改写另一轮。
