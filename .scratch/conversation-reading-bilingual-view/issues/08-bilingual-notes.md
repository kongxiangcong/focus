# 08: 中英文共享小段笔记

Status: ready-for-agent

**What to build:** 中文和原文在对应小段呈现同一条笔记，字符级高亮只显示在读者实际选文的语言中。

**Blocked by:** [03 双语切换与位置恢复](03-bilingual-position.md)、[07 跨小段保存一条笔记](07-shared-chunk-note.md)

[父规格 · 用户故事 20–24](../spec.md#user-stories)

- [ ] 在工作台选择跨 c0、c1 的中文，保存笔记后切到原文。两个对应小段均可查看同一条完整笔记，英文文字保持原样；切回中文，两段只高亮各自选中的字。
- [ ] 从原文侧编辑，在中文侧和逐段精读中可见同一修改。任一处删除，核对两种阅读方式、两种语言及面板均同步。
- [ ] 反向用原文选文记笔记验证高亮的语言归属，并确认独立重点仍按原有选文显示。
