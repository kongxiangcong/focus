# 11: 从旧轮重读，替换该轮最新备份

Status: ready-for-agent

**What to build:** 从当前选中的旧轮重新阅读时，以该轮最新内容创建下一轮，同时替换这一个旧轮的备份和成功时间。

**Blocked by:** [10 在论文管理切换版本并继续读写](10-switch-reading-version.md)

[父规格 · 用户故事 29、32–34](../spec.md#user-stories)

- [ ] 在工作台复现周一从第一轮创建第二轮，周五切回第一轮补写整篇笔记后再重读。论文管理依次列出第一、二、三轮，第一轮仅保留周五的一份结构化备份和一个成功时间。
- [ ] 第三轮继承第一轮周五的整篇笔记，重新准备译文和精读，进度从零、对话从空开始；切回第二轮仍能续接第二轮的进度和对话。
- [ ] 在已有成功备份时通过公共 Host 中断替换，核对原备份内容和成功时间均保留，当前已保存的阅读状态可用。成功重试同一操作后只新增第三轮，恢复第一轮备份可读到周五的内容。
