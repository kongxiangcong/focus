# 02: 一次上传，完整准备后开放阅读

Status: resolved

**What to build:** 一次上传启动本篇完整的阅读准备。逐段精读和对话在同一轮内容全部就绪后一起开放。

**Blocked by:** None (can start immediately)

[父规格 · 用户故事 1–4](../spec.md#user-stories)

- [x] 分别从工作台上传外文 PDF、HTML、Markdown，验证单次操作启动原文、完整译文及映射、阅读计划和全部小段的准备。每轮的译文与经过校验的原文块映射一起发布，可独立于精读计划的小段拼接读取。
- [x] 分别停在仅原文就绪、译文就绪但还缺小段两个阶段。尝试进入两种阅读方式均看到准备状态。全部就绪后两者均可进入，准备本身不增加已读段数。
- [x] 上传中文来源直接使用原文，同样等待计划和全部小段就绪。
- [x] 中断准备后入口可重试；对历史来源复用可用准备结果，补齐缺失项后开放阅读。

## Comments

正式工作台验证外文 PDF、HTML、Markdown 和中文 Markdown 的单次上传、共同就绪和失败重试。公共 Host 验证译文映射、补齐历史资产与精读进度独立。[Host 用例](../../../tests/test_unified_preparation.py)
