# 02: 一次上传，完整准备后开放阅读

Status: ready-for-agent

**What to build:** 一次上传启动本篇完整的阅读准备。逐段精读和对话在同一轮内容全部就绪后一起开放。

**Blocked by:** None (can start immediately)

[父规格 · 用户故事 1–4](../spec.md#user-stories)

- [ ] 分别从工作台上传外文 PDF、HTML、Markdown，验证单次操作启动原文、完整译文及映射、阅读计划和全部小段的准备。每轮的译文与经过校验的原文块映射一起发布，可独立于精读计划的小段拼接读取。
- [ ] 分别停在仅原文就绪、译文就绪但还缺小段两个阶段。尝试进入两种阅读方式均看到准备状态。全部就绪后两者均可进入，准备本身不增加已读段数。
- [ ] 上传中文来源直接使用原文，同样等待计划和全部小段就绪。
- [ ] 中断准备后入口可重试；对历史来源复用可用准备结果，补齐缺失项后开放阅读。
