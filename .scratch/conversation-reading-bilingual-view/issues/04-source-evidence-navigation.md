# 04: 从回答直接定位原文证据

Status: resolved

**What to build:** 激活回答编号后直接看到原文出处；从正文编号回到发起引用的回答。

**Blocked by:** [01 单栏原文与打开原件](01-single-column-source.md)

[父规格 · 用户故事 9、10、13–15、17–19](../spec.md#user-stories)

- [x] 工作台用鼠标和键盘分别激活编号。目标完整可见时就地高亮，跨屏时滚到目标并留下上下文。可准确还原的引文逐字高亮，复杂公式或表格标出可验证的原文块。
- [x] 核对证据绑定来源、解析版本、回答修订及唯一原文范围。缺失范围、引文歧义或版本不符时不猜测命中。已有批注与证据重叠时保留批注样式并在段侧标示证据。
- [x] 让两个回答引用同处，从正文编号一次返回当前所选回答的具体编号并恢复焦点；保留精读段底已有的对话证据入口。连续点两条证据后停在最后成功定位处。
- [x] 桌面保留正文与对话两栏，手机激活引用后进入正文，可通过「查看正文」「返回对话」导航。全程无证据浮卡、选择列表、提示或「回到刚才位置」按钮。
- [x] 手动滚动、键盘翻页可更新阅读书签，证据跳转不推进书签或精读进度。核对后打开原件直达当前可靠页码。
- [x] 在新定位方式接通后移除旧画布、红框、坐标反推、远端页等待及专属样式；检查发布构建已无 PDF.js 依赖资源及静态拷贝。
