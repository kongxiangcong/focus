# 03: 双语切换与位置恢复

Status: ready-for-agent

**What to build:** 读者在同一轮的中文与原文之间切换，并从眼前的段落继续。

**Blocked by:** [01 单栏原文与打开原件](01-single-column-source.md)、[02 一次上传，完整准备后开放阅读](02-unified-preparation.md)

[父规格 · 用户故事 5、6、8、15](../spec.md#user-stories)

- [ ] 已译外文首次打开默认中文，有一处「中文｜原文」控件。手动选择原文后重开本篇，恢复可用的原文视图。中文来源直接显示正文，省去语言控件。
- [ ] 在文章中段来回切换两种语言，视口落在对应段落；滚到别处再切换，以眼前段落为准。切换前后精读当前小段和已读段数一致。
- [ ] 在工作台的精读与对话阅读同一段，核对两者使用本轮同一份译文。普通重开沿用已保存译文。
