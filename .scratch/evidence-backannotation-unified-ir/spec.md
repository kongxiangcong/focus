# 回答证据反标与统一输入解析

Status: ready-for-agent

## Problem Statement

读者点击回答中的引文时，跨栏 PDF 有时只标出第一个框，旋转页和重新解析的页面还可能指错位置。Markdown 标记也会让已经验证的原句在界面上难以找到。读者在中文译文或逐段精读中看到解释，往往还要自己翻回原文、寻找产生这条引用的回答。PDF、HTML 和 Markdown 各自的解析方式使这些问题难以用同一套规则解决。

## Solution

证据卡保留逐字核验的原句，定位默认到段落或对象块。PDF 来源有原文 PDF 和中文译文两个阅读视图。在 PDF 中优先定位证据块，其次定位已知页面，均不可用时直接切到中文译文对应块。在译文中始终就地查看。精读段落列出关联的回答证据，读者可以先看回答，再查原文，随后继续原来的阅读进度。

## User Stories

1. 作为读者，我希望证据卡保留回答引用的原句，以便独立核对。
2. 作为读者，我希望系统拒绝缺失或歧义的引文，以便区分可追溯的陈述。
3. 作为读者，我希望跨段引用保留原文顺序和换行，以便识别两段之间是否省略了内容。
4. 作为论文读者，我希望点击证据时看到跨栏对象的全部可靠框，以便阅读完整对象。
5. 作为论文读者，我希望旋转页也能正确标注，以便辨认对应的段落或图表。
6. 作为论文读者，我希望只有页码可靠时直接跳页，以便自行核对原句。
7. 作为论文读者，我希望 PDF 无法定位时直接进入中文译文对应段落，以便继续查证。
8. 作为译文读者，我希望点击证据后留在译文，以便在当前语言中理解上下文。
9. 作为译文读者，我希望缺少段落对应关系时在当前位置看到原文引文，以便核对仍然可用的证据。
10. 作为长文读者，我希望直接跳到尚未渲染的远端页面，以便及时查看引用。
11. 作为读者，我希望连续点击时以最后一次选择为准，以便打开自己想看的证据。
12. 作为读者，我希望主动滚动能取消等待中的定位，以便掌握当前阅读位置。
13. 作为读者，我希望从高亮编号回到刚才的回答，以便继续讨论。
14. 作为读者，我希望多个回答共用一处证据时能按回答摘录选择，以便返回正确的论述。
15. 作为精读读者，我希望在有关联的段落看到证据条数，以便找到相关讨论。
16. 作为精读读者，我希望先跳到回答中的编号，再决定是否查看来源，以便理解引用的用途。
17. 作为精读读者，我希望证据导航保留阅读游标和书签，以便稍后从原位置继续。
18. 作为历史文章的读者，我希望重解析后仍可核对过去的原句，以便复查旧讨论。
19. 作为历史文章的读者，我希望直接继续提问并获得新证据，以便复用已入库的文章。
20. 作为资料整理者，我希望 PDF、HTML 和 Markdown 都能产出有顺序、有来源锚点的块，以便在同一阅读工作区使用。

## Implementation Decisions

- Answer Evidence 归属确定的回答修订、消息、讨论、Reading Source 和 Parser Bundle。普通导入重新排版的另一份 PDF 时注册新的 Reading Source。bundleVersion 覆盖规范 Markdown 与图片。独立的 layoutVersion 对 IR schema 版本、PDF 原件摘要、正文摘要及规范化页面和块几何取摘要，覆盖顺序、旋转和尺寸。
- 先检验来源及正文版本。PDF 绘框和跳页还须匹配签发时的版面版本。相同来源与正文重新分块时，在保存的行范围内用逐字引文和上下文重新验证，唯一命中后投影到当前块。无法确认时展示历史引文。块编号只在相应解析结果中解释。
- 在工具桥的参数白名单与模型工具说明中同步扩展 read_range 和 cite，保留原有行范围调用，允许可选 block_ids。search 与 read_range 标明块、页和原文行，返回可直接复制的规范 Markdown。统一处理 CRLF 与 LF，用同一份文本计算行号及引文位置。
- cite 在绑定范围内匹配逐字、连续、唯一的 quote，可用相邻的 prefix 和 suffix 消歧。block_ids 只能缩小范围。跨块匹配保留段间换行。图片、表格、公式同样需要可读取的图注、标识或正文。被 Markdown 加粗的引文须保留匹配所需的标记。省略中间块的两处引文分别签发。
- 签发结果保留消息修订、来源版本、引文及所在行，并携带可验证的块、章节、PDF 页面和区域。默认 renderGranularity 为 block。可选的字符投影统一以规范可见文本的 UTF-16 码元表示左闭右开区间，保留链接可见文字和稳定的公式、代码表示。
- Batch B 保留当前正文生成流程。归档识别现有 MinerU 文件及带前缀的 middle、content_list 与 content_list_v2 产物。仅按明确的解析器坐标契约转换为左上原点的归一化坐标，计入旋转，保留同块全部可靠框。坐标未知、越界或缺基准时，只使用独立可确认的页码。同页页级标记聚合展示。利用页面尺寸占位并按需加载，定位远页无需等待全文渲染。
- PDF 有可靠框时标出所有框，仅能确认页时跳页。页码也未知或版面版本失配时，直接切换到中文译文对应块。在中文译文发起时始终留在译文。译文缺少可靠关联时展示原文引文并保留译文阅读位置。主动切换视图按原文块与译文段落的关联同步。
- 来源块上的通用标记若只关联一条回答，直接返回；多条时显示回答摘录供选择。点击刚从回答跳来时高亮的编号直接回到那条回答的出发位置。
- WorkspaceApp 持有当前来源、选择代际与单一 SSE 快照。异步回调核对来源及代际。跨 Tab 定位携带来源、消息、证据、首选视图和 nonce；滚动、提示失败或清空前核对当前意图。命中或判定不可定位后消费一次。新点击取代旧点击，手动滚动取消等待，程序定位滚动可完成。导航、视图或 Tab 切换、全屏切换及 SSE 重连均不得推进 Reading Cursor；证据导航也不更新手动 Reading View Bookmark。
- Batch B 真实 PDF 验收通过后推进 Batch C。三格式从统一的 v1 来源 IR 确定性生成 LF Markdown。IR 保存来源类型、版本、有序块、章节层级、规范文本、原文范围与格式锚点。PDF 保留页与区域，HTML 保留 DOM 块锚点，Markdown 经现有入库状态机导入。
- Reading Plan 的 Reading Chunk 关联原文块。精读仅在有交集的段落展示可展开的「对话证据 · N 条」。点选后先到回答并标出证据编号，再点击才定位来源。历史消息中的证据标记渲染为读者可用的编号。
- 缺少 IR 的旧 Bundle 只读复用现有 Markdown 和可验证的旧 PDF 版面信息。讨论记录可追加回答与新签发的证据。打开、提问和查看历史记录均无需重解析或改写 Bundle。

## Testing Decisions

以生产阅读工作区为主验收入口，复用现有浏览器阅读矩阵、讨论与译文测试方式。通过读者点击后的视图、落点、引文、返回的消息和保存的阅读位置判断结果。签发错误及旧资产兼容复用现有 SourceReading、Host 工具桥及本地 HTTP 测试夹具。观察公开返回值和持久化结果，避免断言内部调用次数或组件结构。

| 场景 | 可观察的验收结果 |
|---|---|
| Batch B 单 PDF 垂直切片 | 真实跨栏、含旋转页的论文经正常入库、read_range、cite、回答编号进入 PDF；核对框与实际对象重合，全部可靠框可见，可从远页反跳回答。 |
| 来源与版面版本 | 重排原件普通导入得到新来源。另固定来源、PDF、正文及图片，仅改变解析几何，正文版本相同而版面版本变化。旧证据可读，点击进入译文，旧页面与框均不用于导航。 |
| 签发边界 | 缺失、歧义、只复制去标记文本或跨越未选中间块均拒签。上下文消歧及真实连续跨块可签发。覆盖 CRLF、链接、Emoji、公式、表格、有无可引用图注。 |
| 当前视图与定位质量 | 覆盖可靠框、仅可靠页、无可靠页、未知坐标空间、缺少译文关联。分别从 PDF 与译文点击，核对实际视图、段落、页码及证据卡原句。同页多个页级标记可区分。 |
| 返回回答与异步竞态 | 单条直接返回，多条可按摘录选择，高亮编号返回出发消息。先点慢页 A 再点 B、等待时切来源或手动滚动，A 迟到后的成功及失败均不得改变新位置、显示过期提示或清除新意图。 |
| Batch C 入库与精读 | 三格式经各自正常入口产生可重复生成的正文与可追溯块。重新分块后关联正确段落。胶囊仅出现在有关联的段落，点击顺序为回答、编号、来源。跨 Tab、返回与重连后核对 Cursor 及书签。 |
| 历史资产 | 打开无 IR 的 Bundle，读取历史引文，继续对话并签发新证据。重新打开后新回答可读，原 Bundle 内容一致。历史回答可读且无裸露证据标记。 |

## Out of Scope

状态栏、完成语义调整、电量进度、主题体系及全局布局属于其他专题。行内逐字着色、UTF-16 偏移签发和 PDF 行框属于可选增强。PDF 来源的阅读界面限定为原文 PDF 与中文译文；规范 Markdown 是签发依据。旧 Bundle 的批量重解析及改写不在本规格范围内。

## Further Notes

Batch B 的放行条件是读者能在真实论文上核对引文，并能在版面不可验证时正确转入中文译文。Batch C 在此基础上推广统一解析与精读联动。架构以 ADR 0034 的来源绑定及导航语义为基础。
