# 04: 让最后一次导航生效

**What to build:** 读者连续点击、切换来源或主动滚动后，等待中的定位不会覆盖新的阅读位置。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 通过生产壳层统一持有当前来源、选择代际和单一 SSE 快照。切来源后让原请求迟到，旧文档、PDF、导读或定位结果均不能覆盖当前来源。
- [x] 一次性跨 Tab 意图绑定来源、消息、证据、首选视图与 nonce。依次点慢页 A 和 B，在 B 完成前后分别让 A 成功或失败，均不能滚动、显示过期提示或清除 B。
- [x] 手动滚轮、触屏、滚动条或键盘浏览可取消等待，程序滚动可正常完成。成功或无法定位时各消费一次，重连不会重放。
- [x] 验证证据导航保留手动书签，视图与 Tab 切换、全屏及 SSE 重连均不推进 Reading Cursor。
