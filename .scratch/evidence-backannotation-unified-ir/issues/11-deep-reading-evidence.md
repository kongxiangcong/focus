# 11: 从精读段落找到回答证据

**What to build:** 读者从精读段落查看关联回答，再自行点选证据编号查阅来源。

**Blocked by:** 08 PDF 从统一 IR 生成可引用正文

**Status:** ready-for-agent

- [ ] Reading Plan 的 Reading Chunk 关联当前原文块，仅在有交集的段落显示「对话证据 · N 条」。用同来源正文重新分块的样本验证关联。
- [ ] 展开并点选后先进入对话，标出对应回答的证据编号。再点编号按当前视图定位来源。历史回答中已签发的证据标记渲染为编号。
- [ ] 以 PDF 来源完成精读、对话、来源和返回的浏览器验收。核对整个过程中 Reading Cursor 与手动书签，重连后不重复跳转。
