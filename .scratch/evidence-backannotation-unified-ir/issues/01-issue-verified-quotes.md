# 01: 按原文范围签发回答证据

**What to build:** 读者从回答编号打开证据卡，即可核对绑定到该条回答修订的规范 Markdown 原句。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 通过 Host 工具桥运行 search、read_range 和 cite。返回的块、页及行标头与可复制正文清晰区分；可选 block_ids 与既有行范围调用均可用。
- [x] 在绑定来源和正文版本内，逐字、连续、唯一的引文可签发；保存实际行范围、原句、上下文及可验证的块和章节。证据卡显示原句，默认定位到块。
- [x] 覆盖 CRLF、LF、链接、Emoji、加粗标记、公式、表格和图注。缺失引文、歧义以及仅复制去标记文本时拒签；精确上下文能消除歧义时可签发。
- [x] 连续跨块引用保留换行。选择不相邻块时不能跨越被省略的正文；没有可引用正文或图注的图片不能凭空签发。
