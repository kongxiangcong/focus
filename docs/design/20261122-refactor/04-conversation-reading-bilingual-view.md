# 设计文档 04 · 对话阅读的单栏正文、双语证据与侧栏目录

2026-11-24 · 产品方案待实施。阅读版本支持备份、切换与继续编辑。适用于对话阅读区、来源文档、翻译映射及论文管理。基线版本为 `c564a3f70d2436f89456fadc098d0e1d1b3514f1`。

阅读准备全部完成后，读者打开论文即可阅读正文。点击回答里的引用编号，正文在当前语言直接定位并高亮，前后段落留在视野内。读者可从侧栏目录跳节，也可在需要核对表格、公式或版面时单独打开原件。

## 1. 上传、翻译与重新阅读

1. 上传 PDF、HTML 或 Markdown 后，一次上传启动本篇完整的阅读准备。原文解析完成、外文译文及映射就绪、精读计划生成且全部小段准备完成后，同时开放「逐段精读」和「对话」。中文来源直接使用原文，其余就绪条件相同。
2. 每个阅读版本使用本轮的一份译文。生成译文时随内容保存对应的原文块标识。翻译可以利用跨段上下文，输出仍须标明各译段对应的原文范围。标题、图表、公式、附录和参考文献均按原文顺序出现；无需翻译的内容在原位呈现。
3. 读者确认「重新阅读」后，先完整备份当前阅读版本。备份成功后，新一轮获得重读时各条整篇笔记的独立副本，从空的小段笔记、句子备注、重点与讨论开始。重新生成精读计划、重新划分小段，对外文来源重新翻译。新一轮精读从新计划的第一段开始，已读段数归零。只有「重新阅读」触发对已有完整译文的重译。新译文及其原文映射完整且校验成功后一起替换当前译文。新一轮准备失败时，阅读入口提供重试。旧译文不能代替本轮重译的结果。
4. 原始来源与 Parser Bundle 版本相同时，即使重新阅读改变了精读小段的边界，归档回答里的原有引用仍指向同一处原文。重新解析产生不同版本时，沿用来源版本校验规则。

### 1.1 阅读版本与论文管理

一次「重新阅读」自动备份这篇论文当时已保存的整体阅读状态。每个阅读版本只保留最近一次成功的结构化备份和该次备份时间。再次从同一轮重新阅读时，用该轮最新保存的状态替换上一份备份，同时更新时间。备份记录来源、阅读版本标识与对应的解析版本，并保留下列内容及其关联。

- 精读计划、小段划分、当前小段、已读进度及阅读书签。
- 本轮译文、译段到原文块的映射，以及对应的文章结构与导读。
- 整篇笔记、小段笔记、句子备注、重点及选文位置。跨小段笔记保留同一条笔记与各小段的关联。
- 本轮可见的对话、消息修订、讨论摘要及回答证据。引用保留与具体回答、原文位置的关联。

备份完整且可读取后才开始重置。备份失败时保留当前阅读状态；如该轮已有成功备份，其内容与时间也保留。中断后重试同一次重读，成功时只追加一个新轮次。新一轮准备失败时，已完成的备份仍可从论文管理选取。

在论文管理中可查看一篇论文的阅读版本，每轮列一项，标明当前选中的版本，已有备份的轮次显示最近一次成功备份的时间。切换使正文、译文、笔记、重点、精读位置和对话一起显示为所选版本的状态。切回任一已就绪的阅读版本后，可从该轮上次的精读位置继续、编辑笔记，并在该轮原有的对话里接着提问。进度、笔记、重点和对话的变更均保存到操作所属的阅读版本。再次切回该轮时恢复最近保存的状态。当读者从任一轮发起「重新阅读」时，先备份当前选中轮次最近保存的状态，再按这篇论文的创建顺序追加一轮。新一轮从所选轮次复制整篇笔记，各轮随后独立保存修改。论文管理按轮次平铺列出所有版本。

## 2. 打开正文与切换语言

PDF、HTML 和 Markdown 共用单栏正文排版、字号、主题、选文与批注交互。图表在相应段落出现；宽表、代码、公式可在块内横向滚动。

在对话正文选中文字点「记笔记」，所选文字带入草稿，一次保存一条小段笔记。选文跨越精读小段时，仍用同一操作。逐段精读在选文覆盖的每个小段显示同一条笔记。笔记保存成功后，自动高亮选中的文字，各小段只高亮本段内的选文。取消草稿不会新增高亮。同一条笔记在笔记面板只列一次，在任一处编辑，所有显示位置同步更新。删除一次，所有位置的这条笔记及其自动高亮一并移除。读者单独标过的重点继续显示。直接从笔记面板新建、未关联正文位置的笔记归入整篇笔记。

中文与原文在对应小段显示同一条笔记。笔记的文字高亮只显示在实际选文的语言中，切回该语言时恢复原选文的高亮。

| 场景 | 正文与控件 |
|---|---|
| 首次打开已译外文 | 默认中文，语言控件固定为「中文｜原文」。后续打开优先恢复本篇手动选择的可用语言。 |
| 阅读准备进行中 | 阅读入口显示准备状态，全部就绪后开放两种阅读方式。 |
| 阅读准备失败或中断 | 在准备状态处提供「重试」。历史来源已有的可用准备结果继续复用，缺失项在进入阅读前补齐。 |
| 中文来源 | 直接显示正文，省去语言控件。 |

切换语言后继续看当前段。读者刚点过引用且该段仍在视野内时，切换后直接看到另一语言对应的高亮；已经手动读到别处时，则以眼前段落为准。手机两区沿用「正文 / 对话」语义，入口使用「查看正文」「返回对话」。

正文工具栏只提供一处「打开原件 ↗」，按原件可用性显示。PDF 有可靠页码时打开当前所读内容对应页。刚定位到证据即打开，可到达证据页；继续滚动再打开，以新位置为准。页码未知时直接打开文件，HTML 原件按自身地址打开。

## 3. 点击引用只定位和高亮

**一次点击只做两件事：定位、高亮。** 在回答里点击或用键盘激活编号，桌面保留两栏，手机切到正文。目标已经完整可见时直接高亮；需要滚动时给目标段前后留出上下文。引用导航全程不弹卡片、气泡、选择列表或提示，也无需关闭任何东西。

| 环节 | 规则 |
|---|---|
| 证据签发 | 沿用 `SourceReading.cite` 对原文逐字引文与唯一范围的校验。证据绑定来源、解析版本、消息修订以及原文位置。英文论文的依据始终是英文原文。 |
| 原文显示 | 从已校验的原文范围确定目标块。能还原准确文字时在段内标出引文；涉及表格、公式或复杂排版时高亮可验证的原文块。 |
| 中文显示 | 从同一原文块找到对应译段并高亮。译文仅参与显示。重译只更新块与译文的对应内容。中英文共用一个活动证据，切换语言即可核对另一侧。 |
| 历史来源 | 继续读取已有来源与证据。没有 Source IR 时沿用规范 Markdown 与原文行范围。已有翻译只能验证到一组段落时，高亮该组；连组对应也无法验证时，在该处保留可验证的原文块。段数相等本身不足以建立逐段对应。 |
| 返回回答 | 正文证据编号绑定具体回答里的具体引用，激活后直接回到对应位置并恢复焦点。同段被多轮引用时，正文显示当前所选回答的编号，避免让读者再选一次回答。 |
| 跳转后继续阅读 | 正文停在刚定位的段落，读者可从这里向下读。连续点击多个引用时，正文停在最后一次成功定位的位置。省去「回到刚才位置」按钮。 |

临时证据高亮与永久重点、备注各自可辨；重叠时保留用户批注样式，以段侧标记表达证据。阅读书签记录手动滚动、键盘翻页和目录跳节的位置。以上动作、引用定位及语言切换均不推进逐段精读进度。

## 4. 阅读区侧栏目录

阅读区侧边栏内设独立的「目录」区域，与正文和对话各有明确位置。文章导读保留概览文字，章节跳转集中到侧栏。正文顶部省去常驻完整章节路径。

- **按正文层级列出分段标题。** 例如「1 引言」「2 方法」「2.1 数据来源」「2.2 实验设置」。沿用原有章节号；标题无编号时按层级补显示编号，已有编号只显示一次。每项对应正文的真实标题与起始块。没有标题的文章省去空目录。
- **支持两层折叠。** 「目录」可整体收起和展开；有子节的章节可单独收起和展开。展开箭头只控制子项，点击标题只跳节。收起目录或章节时正文停在原位。
- **跟随阅读位置。** 当前小节有选中态，父节已折叠时标记最近可见的父节。引用跨节或切换语言后按当前位置更新选中态，保留读者的展开选择。中文标题已有可靠对应时随中文视图显示；否则沿用原文章节名。
- **窄屏优先留给正文。** 宽屏默认展示目录区，窄屏默认收起，保留「目录」入口。手机点选标题后收起目录，直接看到对应小节。整体开合与分支开合都可用键盘操作。

## 5. 实施边界

- `ConversationReader.tsx`、`PaperViews.tsx` 与 `paper-evidence.ts` 改用统一正文渲染及原文块定位，删除内嵌 PDF 画布、红框、坐标反推、远端页等待和证据浮卡。清理专属样式、`pdfjs-dist` 依赖与 Vite 静态资源拷贝。保留原件链接与已验证页码。
- `ReadingDocument` 提供有序原文块、原文范围、章节层级、可选页码及当前译文映射。复用 Source IR 的 `sections`、`blocks`、`source_lines` 和 `page_number`；兼容缺少新字段的 Host。现有 `shared_translation` 从精读计划拼接译文，实施时须使来源译文可独立于精读计划复用。
- 保留回答证据身份、一次性证据跳转、独立阅读书签及精读段底部已有的对话证据入口。旧 Bundle 只读兼容。本文更新文档 00、01 的常驻 PDF 与版面框展示条款，阅读入口按 §1 的统一就绪条件开放。沿用文档 03 的主题规则、ADR 0034 的证据契约和 ADR 0035 的精读重置语义。

## 6. 验收

| 场景 | 可观察结果 |
|---|---|
| 分别上传外文 PDF、HTML、Markdown | 每种格式均自动准备中文。分别在仅原文就绪、翻译完成但小段尚未全部就绪时尝试进入，两种阅读方式都显示准备状态。全部就绪后两者均可进入。首次打开已译来源默认中文，手动切换后重开能恢复选择。中文来源直接读正文。 |
| 在中文与原文中核对同一条引用 | 从回答点一次编号就看到对应段落高亮与上下文，全程无弹层或提示。切换语言后仍是同一条证据，原文可核对逐字引文。 |
| 在回答中依次点两条引用 | 正文停在第二条引用对应的位置，可直接向下读，全程无「回到刚才位置」按钮。点正文侧的引用编号可回到发起引用的回答。精读进度保持原值。 |
| 同一自然段被切成 c0 和 c1，在对话正文选中 c0 末尾到 c1 开头的文字并保存笔记 | 精读时两段各自高亮选中的部分，两段都能看到同一条完整笔记。笔记面板只列一条。在 c0 编辑后，c1 和对话正文显示新内容；仅通过「记笔记」产生高亮时，在 c1 删除一次，c0、c1 和对话正文同步移除笔记及其自动高亮。 |
| 中文选句记笔记后切到原文，再切回中文 | 保存后所选中文自动高亮。原文对应小段可见同一条笔记，英文文字保持原样。切回中文仍可见准确的选文高亮。 |
| 先将一句话单独标为重点，再在同一处记笔记并删除笔记 | 所有位置同步移除该笔记，读者先前单独标记的文字仍显示为重点。 |
| 选中一处尚未标记的文字并取消笔记草稿 | 该处没有新增笔记或高亮。单独标重点时可直接高亮选文。 |
| 从正文选句记笔记，再从笔记面板单独新建一条 | 在逐段精读的对应小段能找到前一条，编辑后切回对话可看到修改；后一条归入整篇笔记。确认重新阅读后，新一轮只保留后一条，旧版本仍可查看两条笔记。 |
| 重新阅读一篇已有译文、已读过若干小段的外文来源 | 普通重开沿用当前译文。确认重新阅读后重新规划、切段和翻译。新一轮可查看整篇笔记，小段笔记、句子备注和重点仅留在旧版本。进入新计划时从第一段开始，已读段数为零。同一解析版本下，归档回答的同一引用仍可定位原文，重译成功后可定位对应的新译段。 |
| 重新阅读前有跨段笔记、重点和带引用的对话，随后在论文管理切回旧版本 | 一次切换可读到旧译文，在两个原小段看到同一条笔记及选文高亮，恢复该轮精读进度；旧回答的引用仍能定位对应原文。切回新版本后显示新一轮自己的进度和对话。 |
| 从第二轮切回第一轮，继续读一段并在原对话追问，再往返切换 | 第一轮保留新增的进度与问答。第二轮恢复自己的进度、对话与译文。 |
| 第一轮写整篇笔记「这个实验值得复现」，重读后在第二轮改为「已复现，结果一致」 | 在论文管理往返切换时，第一轮显示原句，第二轮显示修改后的内容。 |
| 周一从第一轮开启第二轮，周五切回第一轮补写整篇笔记，再点「重新阅读」 | 第一轮只保留周五的备份和时间，备份包含刚保存的笔记。论文管理依次列出第一、二、三轮。第三轮继承第一轮此时的整篇笔记，从零准备新精读和新对话；切回第二轮仍能续接第二轮的进度与对话。 |
| 备份写入中断，再重试同一次重新阅读 | 原状态完整可用。成功重试后版本列表只新增一轮，能够打开其译文、笔记和对话。 |
| 带多级标题的论文 | 侧栏展示如「1」「1.1」的标题，已有章号无重复。展开分支不滚动正文，点标题一次即到对应小节。收起整个目录后可重新展开；引用跨节后选中态正确。 |
| 核对原件 | 从第 8 页的引用打开 PDF 直达第 8 页，手动读到第 12 页后从同一入口打开可直达第 12 页。缺页码也能打开原件。 |
| 不同屏宽与历史来源 | 在 1440px 和 390px 下正文、目录及对话可用。图表、公式与附录完整，批注清晰，页面无横向溢出。无 IR 的历史来源可读，无法验证的译段不会被错误标亮；构建不再携带 PDF.js 资产。 |
