# FOCUS 阅读页重设计：实施规范（阅读镜头 · 手动讨论吸附）

状态：方向已选定（2026-10-19 修订），尚未实施。
基础：PR #19 `feat/cds-ui-presentation` @ `07c0fee`。main @ `6070204` 仅作体验参考。
参考原型：`ui/apps/standalone/src/prototypes/focus-directions/`（未跟踪，`?d=c` 为阅读镜头，`?d=ab` 为吸附布局参考）。原型不含“手动吸附按钮”，凡与本文冲突以本文为准。
执行约束见 §11，任何实施前必须先读。

## 0. 已确认决策

| 决策 | 内容 | 影响 |
| --- | --- | --- |
| 方向 | **C 阅读镜头**：按时间排列的连续阅读流，一块浮动表面跟随“正在看的段落及其讨论”滑动 | 展示层 |
| 讨论吸附 | 功能区新增「吸附讨论」开关，**手动**把讨论移到所属段落右侧并吸附；默认关闭；不自动切换 | 展示层 + 本地视图偏好 |
| 图片 | 按需打开：段落内缩略图 →「放大」或「在资料栏固定」；新段落不再自动打开资料 | **业务行为变更**：需新 ADR 替代 ADR 0019/0023 中由 `pictureContext` 驱动的自动选择与开合 |
| 让位 | 资料打开时正文整体平移让开，宽度与换行不变；空间不足退回覆盖 | ADR 0023「不挤压正文」收紧为「不改变正文宽度」 |

不改变：新会话、继续、回看、重新阅读、笔记保存、草稿、请求身份与恢复语义；资料四类内容；全屏下行为一致。

**术语**：领域里的 Reading Cursor（`CONTEXT.md`）是持久的阅读前沿。C 方向的视觉效果在代码与界面中一律称「阅读镜头 / Reading Lens」，不得命名为 cursor/光标，也不得写入 Cursor State。镜头只反映“正在看”，不改变进度，也不改变「继续」打开的段落。

## 1. 设计语言

1. **一个视觉中心**：整条阅读流只有一块表面（镜头：卡片底色 + 阴影），覆盖正在看的段落与紧随其后的讨论；其余内容直接落在画布上。
2. **渐进隐退只作用于容器与辅助信息**：边界、阴影、底色、元信息先退；正文只降一档或两档墨色，不用 opacity，不随鼠标经过恢复。
3. **两种强调永不混用**：靛青 = 交互状态与位置（选中、当前进度、焦点环、回看、镜头内讨论竖线）；琥珀 = 内容重点（被引用的原文、引用条）。正文不自动染色。
4. **一个主按钮**：「继续」是唯一实心按钮（发送在输入区内是局部主按钮）；其余为 ghost。
5. **动效只表达三件事**：位置变化、状态反馈、内容关联；业务调用从不等待动画。

## 4. 组件与状态

### 4.1 阅读流与阅读镜头

- **阅读流**：沿用 PR 的时间顺序渲染（段落事件、回看事件、提问与回答按发生顺序排列）。一个“段落组” = 一个段落事件 + 其后直到下一个段落事件之前的讨论。
- **镜头**：阅读流容器内一个绝对定位、`pointer-events: none`、`aria-hidden` 的表面；用 `transform: translateY` 与 `height` 定位到“正在看的段落组”，左右各外扩 30px，上下各外扩 18px，圆角 18。
- 段落组状态：

| 状态 | 判定 | 表现 |
| --- | --- | --- |
| focus | 段落组 = 正在看（§6.4）；未滚动时 = 最新段落 | 镜头覆盖；正文 `ink`；讨论竖线 `accent-line`；段落工具常显 |
| near | 与 focus 相邻 | 正文 `ink-2` |
| far | 其余 | 正文 `ink-3` |
| review | focus 段落序号 < 阅读前沿 | 镜头叠加 1.5px 虚线 `accent-line` 外框；功能区定位器变为「回看 N · 进度 M/T」+「回到进度」 |
| 新出现 | 挂载后首次出现的事件 | 仅一次入场（§5）；恢复的历史不播放 |

段落工具（引用提问、原文/译文）在非 focus 段落仅于 hover/focus-within 显示（只改透明度，不改布局）。

### 4.2 手动讨论吸附（新增）

- **入口**：功能区「吸附讨论」切换按钮，`aria-pressed`；默认关闭。偏好存于浏览器本地，与现有阅读外观偏好同处，不写入 Knowledge Base，不属于 Cursor State。
- **生效条件**：开关为开 **且** 阅读区宽度 ≥ 1240px **且** 资料抽屉关闭。条件不满足时开关保持“开”但布局暂时退回阅读流，按钮 `title` 说明原因（「窗口较窄」/「资料已打开」）；条件恢复后自动重新吸附。从不因宽度变化自动打开开关。
- **布局**：每个段落组变为两栏：原文 720 | 间距 40 | 讨论 ≥300（左侧 1px 分隔线）。讨论栏 `position: sticky; top: 14px`，在其段落组范围内吸附；讨论高于原文时行高随讨论增长，原文顶对齐。无讨论的 focus 段落右栏显示虚线「＋ 就这段提问」。镜头同时覆盖两栏。
- **归属**：消息归到 `reference.chunkId` 所指、且在本会话中位于该消息之前的最近一次段落出现；无引用或找不到时归到时间上紧邻的前一个段落组；之前没有段落的消息留在流顶部。
- **切换**：先捕获阅读锚点（§6.5），切换布局后恢复；原文宽度不变、不重新换行；讨论栏 140ms 淡入，镜头随新尺寸平滑重定位；不改变 Cursor、不发请求。
- 宽屏吸附时回答常驻视野，「回到最新」仍按 §6.7 规则出现。

### 4.3 段落图片

段落末尾的缩略图条：92×58 缩略图 + 图号 + 单行图注 +「在资料栏固定」。点缩略图 → 查看器（共享元素放大）；点「固定」→ 打开资料栏图片页并选中该图。不再在新段落自动打开资料。

### 4.4 讨论

- 提问：右对齐浅色气泡；其上方为引用条（琥珀「第 N 段」+ 虚线下划线摘录）。点击引用条 → 跳到原文并高亮该句（§6.3）；悬停引用条 → 原文对应句临时琥珀高亮。
- 回答：无闭合卡片；头部「FOCUS」+ 运行状态；流式中仅显示静态光标块，不闪烁、不逐字动画；完成后显示「存为笔记 / 复制 / 回看第 N 段」。回答内图片为 380px 宽可放大缩略图。
- 选中原文 → 选区上方浮出「引用所选提问」，点击写入输入区引用条并聚焦。

### 4.5 功能区（输入区上方一行）

顺序：资料 · 定位器（序号/总数 + 章节，点开为文章结构浮层）·［回到进度］· 弹性空白 · 吸附讨论 · 新会话 · 全屏 ·［提问（输入区收起时，带草稿点）］·［停止（收起且运行中）］· 继续（主按钮，文案「继续 · 第 N 段」/「完成本篇」/「已读完」）。
PR 中独立的「结构」按钮并入定位器浮层顶部的「文章结构总览」入口（ArticleStructure 视图本身保留）。< 600px 时「吸附讨论」隐藏。

### 4.6 输入区

Editor + 引用条 + Chin（收起 · 提示 · 发送/停止）。圆角 14；聚焦为 1px `accent-line` + 4px `accent-soft` 外环。收起：草稿与引用保留，整行释放，功能区出现「提问」；收起前预留尾部空间（§6.6）。IME：`isComposing || keyCode === 229` 时 Enter 不发送。

### 4.7 资料抽屉

左侧覆盖，`min(400px, 区域宽 - 24px)`，距边 12px，圆角 14，浮层阴影；分段控件：图片 N / 笔记 N / 进度 / 讨论。图片页：大图（可放大）+ 图注 +「回到第 N 段」+ 3 列缩略网格（选中为 2px 靛青环）。Esc 关闭并把焦点还给「资料」。

### 4.8 浮动入口（阅读区底部居中）

「↩ 返回刚才位置」（程序跳转后出现）、「回到最新 ↓ / 回答生成中 · 回到最新 ↓」（离开最新内容且有新内容时出现，实心）。

## 5. 动效

时间：`quick 140ms`、`move 240ms`、`travel 380ms`、`exit 170ms`。曲线：`out cubic-bezier(.22,.8,.24,1)`、`inout cubic-bezier(.45,0,.2,1)`、`in cubic-bezier(.4,0,1,1)`。替换 PR 的 60/120/200/300/450 与 overshoot（阅读页不使用回弹）。

| 场景 | 属性与参数 | 打断 / 快速反复 | 低动态 |
| --- | --- | --- | --- |
| 继续 → 新段落入场 | opacity 0→1 + translateY 8px→0，move/out | 只对新事件；连续点击由 pending 锁合并 | 仅 opacity 120ms |
| 继续 → 滚动落位 | rAF 滚动 280–520ms（随距离），easeOutQuart | 任意滚轮/触摸/滚动键立即取消 | 立即定位 |
| **镜头移动** | transform + height，travel/inout；墨色同步过渡 | CSS transition 从当前位置改道，不排队 | 立即定位，无过渡 |
| 镜头回看外框 | outline-color，move | 自然反向 | 同 |
| **吸附开/关** | 讨论栏 opacity 140ms；镜头随尺寸 travel 重定位；滚动位置由锚点瞬时修正（不做滚动动画） | 快速反复只保留最终状态 | 无过渡 |
| 新提问/回答出现 | 同新段落入场 | 同上 | opacity |
| 流式增量 | 无动画 | — | — |
| 资料开 | translateX(-20px)→0 + opacity，move/out；正文让位 translateX，move/out | 用 transition（非 keyframes），反复开关从当前帧反向 | 无位移 |
| 资料关 | 反向，exit/in；visibility 延迟到结束 | 同上 | 无位移 |
| 输入区收起/展开 | grid-template-rows 1fr↔0fr + opacity，move/out | 过渡可反向 | 同 |
| 结构浮层 | scale .98 + translateY 4px + opacity，move/out；退出 exit/in；origin 左下 | 同上 | opacity |
| 图片放大 | 缩略图几何 → 查看器（WAAPI FLIP），300ms/out；背景 200ms | 打开中关闭 → `animation.reverse()` | 120ms 淡入 |
| 图片关闭 | 回到来源几何 220ms；来源不可见则淡出 | 同上 | 100ms 淡出 |
| 引用高亮 | CSS Custom Highlight，保持 2.4s | 新跳转覆盖旧高亮 | 同 |
| 按下 | 主按钮 scale .98，60ms | — | 无 |

禁止：持续呼吸/闪烁（任务点改为静态色点）、整页漂移、历史重复入场、hover 改变镜头位置或段落强调。入场用 CSS，“新”标记在挂载时一次性计算，不用 `setTimeout` 清除（替换 PR 的 `freshEvent` 定时器）。低动态 = 用户设置或 `prefers-reduced-motion`。

## 6. 滚动与视觉追随（替换 `settle()` 的职责划分）

1. **起读线** = 阅读区顶部 + max(24px, 10% 高度)。
2. **继续落位**：新段落顶部对齐起读线（长短段落一致）；落位期间锁定“正在看”为新段 700ms，镜头直接去新段，不逐段扫过。
3. **程序跳转**（引用条、结构浮层、资料内链接）：目标块置于起读线下 40px，记录原位置并显示「返回刚才位置」；不改变 Cursor。
4. **正在看**（驱动镜头）：阅读线 = 顶部 32%；取最后一个顶部在阅读线之上的段落组；跨越边界需超过 24px 且候选保持 140ms 才提交。鼠标经过不参与。
5. **锚点保持**：布局变化（吸附切换、资料让位、字体/窗口变化）前记录阅读线处第一个原文块及偏移，布局后按差值修正 scrollTop；容器保留 `overflow-anchor: auto`。
6. **尾部空间**：`max(128px, 视口 - 起读线 - 最后段落组高度, 当前可见底部超出内容的部分)`；收起输入区前额外预留输入区高度 700ms。目标收起位移 0（main 72px，PR 77px）。
7. **流式跟随**：「最新」= 流式中的回答底部（吸附时位于右栏），否则为内容末尾。距视口底 ≤48px 视为在底部 → 跟随（按帧即时对齐）。向上滚轮/触摸/PageUp/Home/↑ 立即停止并显示「回到最新」；用户滚回底部即恢复。发送后仅在提问块低于视口 60% 时把它带到 45% 处。

## 7. 响应式

| 阅读区宽度 | 布局 |
| --- | --- |
| ≥ 1240px，吸附开，资料关 | 段落组两栏 + 吸附讨论 |
| ≥ 1240px，吸附关或资料开 | 阅读流单栏；资料开时正文让位 |
| 600–1240px | 阅读流单栏；吸附暂停；资料打开时空间足够则让位，否则覆盖 |
| < 600px | 隐藏工作台导航与「吸附讨论」；功能区横向滚动；控件命中高度 ≥ 40px；镜头外扩缩为 12px；资料为全宽覆盖 |

全屏：隐藏工作台导航与页头，其余规则相同。

## 9. 实施顺序

每步独立可验证、单独停下等待用户确认。第 1–4 步只涉及颜色、排版、动效，不改业务行为。

1. **颜色 token**（§2）：`focus-tokens.css` + `standalone.css` 引用处；验收：深浅色截图、关键文字对比度（`ink-3` ≥ 7:1、次要文字 ≥ 4.5:1）、陶土色不再出现在阅读页。
2. **排版**（§3）：`reader-shell.css`、`mist-reader.css` 中的正文/回答/表格/代码/公式；验收：真实文章含公式、表格、代码的截图，720 宽，无横向溢出（390/1024/1440）。
3. **基础动效**（§5 除镜头/吸附/图片外）：动效 token、入场一次性、资料 transition 开合、输入区收起、结构浮层、低动态；验收：快速反复开关可反向、历史不重播、低动态下无位移。
4. **阅读镜头**（§4.1、§6.4、镜头动效）：段落组标注、墨色三态、镜头定位与提交；验收：滚动时镜头不逐段闪动、hover 不影响、回看外框与定位器文案、不改变 Cursor。
5. 滚动控制器（§6 其余）。
6. 手动讨论吸附（§4.2）。
7. 按需图片（含新 ADR 与测试修改）、让位、查看器 FLIP。
8. 讨论交互（引用条跳转/高亮/返回、选区引用、回答动作）。
9. 全量回归与证据；用户确认后再决定是否替换生产界面。
