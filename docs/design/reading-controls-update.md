# 阅读控制补充（2026-10-21）

依据：用户在 PR #24 开发过程中的明确修改要求。本页记录当前分支的产品决定；PR 合并／部署状态与设计接受状态分开。

- 阅读宽度从设置页移至阅读页“宽幅”按钮内的横向滑杆；中点为默认“标准”，拖动实时调整并保存浏览器偏好。旧设置页宽度入口及二态宽幅切换被替代。
- 删除亮度设置及其阅读区滤镜，旧亮度偏好停止生效；替代 ADR 0025 中亮度偏好保持可读的要求。
- 小屏导航保留用户展开能力与可达的专题入口；窗口变窄不能用样式永久锁定折叠。
- 已完成文章显式打开时直接展示全部已保存段落，隐藏继续按钮；保持进度、笔记、讨论和来源引用。新会话仍先清空显示，重新打开来源后恢复全文。参见 ADR 0018 的同日补充。
- 返回位置、回到最新、回到进度、回看提示提供 ×。关闭只隐藏提示，不滚动或推进进度；同一次流式更新不会立即重新显示。
- 结构首页、无讨论的第一段以及已在最新位置时不显示“回到最新”。提示统一放入底部功能区的位置／导航组，不覆盖正文；外层和按钮没有装饰边框，键盘焦点指示保留。

- 阅读功能区移除“新会话”。左侧为当前位置与可关闭的导航提示，右侧依次为资料、行宽、笔记、全屏、收起／提问、继续。窄屏自然换行；最窄屏“继续”省略次要段号，段落位置仍在位置徽标中显示。
- “吸附笔记”入口简称“笔记”，默认开启。普通窗口和全屏均可用；能容纳原文列 + 间距 + 280px 笔记列时外侧并列，否则阅读段内部正文与笔记按 3:1 分栏。笔记栏独立滚动且限高，底部始终保留“就这段讨论”。打开资料不关闭笔记偏好。详见 ADR 0031。

以上决定不改变资料抽屉的已接受行为。旧 ADR 与当前样式若有差异，应记录并单独核对；不能因整理文档而默许代码偏差。

验证记录：PR #24 的五项独立修复及首页提示追加修复包含前端/后端回归和类型检查；桌面、移动端实际浏览器验证受连接环境限制，仍未完成。本文不是视觉验收通过记录。

## 正文组讨论折叠（2026-10-23）

正文和其后讨论之间使用 `--reader-line` 的浅灰细虚线，右侧提供轻量“收起讨论／展开讨论”按钮。仅有讨论的正文出现组显示入口；收起保留完整正文、笔记和高亮，隐藏该组全部用户与助手对话。重复出现的同一 chunk 各自独立，前置独立讨论不套用正文分隔。

默认展开。使用前端 localStorage 偏好，按知识库、来源、会话、讨论、正文事件身份隔离，键为 `focus.discussionFold.v1:` 加 JSON 身份数组。没有事件 ID 的兼容数据沿用事件序号键；不迁移无法区分正文出现次数的旧 chunk 键，不改业务消息或数据库。只有值 `true` 表示收起，非法/未知旧值忽略；存储不可用时使用内存。

主动收起不停止生成，增量不展开，可显示“生成中”，原停止按钮仍可用。发送新问题时展开时间线尾部接收问题的组，引用旧段不会重新归档历史消息。折叠与 composer 收起、笔记折叠互不关联。按钮提供 `aria-expanded` / `aria-controls`，隐藏区域不参与 Tab；操作后焦点留在按钮。折叠不加动画，滚动以仍存在的按钮为锚，长回答底部收起时将入口保留在视口。

本次验证见 [讨论折叠验证记录](discussion-fold-validation.md)。

## 单一“回到最新”提示（2026-10-23）

用户明确修改：取消“正在回看…正式位置未改变”、“回到进度”、“返回刚才位置”等独立提示和返回入口，功能区仅保留一个可关闭的“回到最新”。位置徽标仍显示当前位置与总段数，不再另写“回看…进度…”提示。

关闭状态按知识库、来源、会话、讨论及实际阅读前沿的 plan/chunk 标识隔离；在同一前沿期间，滚动、重复回看、引用定位、切换资料、流式增量均不能解除。推进到下一段只开启新的触发周期，旧视口的回看状态不能立即触发；落位后再次回看才显示。关闭状态仅保存在当前 reader 内存，切换来源/会话后再切回仍记住，刷新/重挂载重置；未要求跨刷新持久化，不新建存储偏好或修改业务进度。

“回到最新”优先恢复正在生成回答的跟随；没有生成任务且时间线末尾只是旧段回看记录时，定位实际进度段，否则沿用最新内容定位。它不再提供“返回刚才位置”的滚动撤销语义。关闭不滚动、不停止生成；关闭或返回后焦点移到持续存在的位置入口（非 Mist 则为输入区/阅读区）。沿用现有 ghost 样式、主题与减少动效规则。

## 工作台导航边缘调宽（2026-10-23）

用户指定最左侧工作台导航栏。桌面展开时，其右边缘支持拖拽调宽，沿用默认288px，范围240–420px，并为主体保留至少480px；数值由 focus-tokens.css 的导航 token 管理。拖动直接跟随指针，不做宽度动画；3px 阈值区分点击与拖动，释放提交，取消／丢失捕获／Escape 恢复拖动前宽度。仅拖动期间禁用选择。

拖柄是可聚焦的垂直 separator，方向键按16px调整，Home/End到边界，Enter或双击恢复默认。收起仍为56px，展开恢复所选宽度；窗口缩小临时约束有效宽度，再放大恢复所选宽度。≤760px顶部导航和阅读全屏不显示横向拖柄。宽度只保存在当前 WorkspaceApp 内存中，切路由、收起不丢失，刷新恢复默认；未新增跨刷新存储。资料抽屉和吸附笔记栏不在本次范围。
