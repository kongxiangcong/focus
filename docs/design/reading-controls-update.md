# 阅读控制补充（2026-10-21）

依据：用户在 PR #24 开发过程中的明确修改要求。本页记录当前分支的产品决定；PR 合并／部署状态与设计接受状态分开。

- 阅读宽度从设置页移至阅读页“宽幅”按钮内的横向滑杆；中点为默认“标准”，拖动实时调整并保存浏览器偏好。旧设置页宽度入口及二态宽幅切换被替代。
- 删除亮度设置及其阅读区滤镜，旧亮度偏好停止生效；替代 ADR 0025 中亮度偏好保持可读的要求。
- 小屏导航保留用户展开能力与可达的专题入口；窗口变窄不能用样式永久锁定折叠。
- 已完成文章显式打开时直接展示全部已保存段落，隐藏继续按钮；保持进度、笔记、讨论和来源引用。新会话仍先清空显示，重新打开来源后恢复全文。参见 ADR 0018 的同日补充。
- 返回位置、回到最新、回到进度、回看提示提供 ×。关闭只隐藏提示，不滚动或推进进度；同一次流式更新不会立即重新显示。
- 结构首页、无讨论的第一段以及已在最新位置时不显示“回到最新”。该浮动提示外层和按钮没有装饰边框，键盘焦点指示保留。

以上决定不改变资料抽屉的已接受行为。旧 ADR 与当前样式若有差异，应记录并单独核对；不能因整理文档而默许代码偏差。

验证记录：PR #24 的五项独立修复及首页提示追加修复包含前端/后端回归和类型检查；桌面、移动端实际浏览器验证受连接环境限制，仍未完成。本文不是视觉验收通过记录。
