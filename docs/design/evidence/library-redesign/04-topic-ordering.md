# Step 4: Topic information and ordering

Sidebar Topics now show completed/total counts using the shared phase mapping. The presentation-only `UNFILED` sentinel is `/__focus_unfiled__`; Core's existing `_identifier` allows only alphanumeric characters and hyphens, so this value cannot be a real Topic ID. It is used only for local filtering and survives source-list refresh. Unfiled navigation appears only when a source has no Topic; a currently selected empty Unfiled option remains available in the selector so the controlled selection stays coherent.

The narrow-screen selector and sidebar use the same WorkspaceApp Topic state. The selector also remains available when the user manually collapses the sidebar. `TopicHead` replaces the bare rename/delete buttons with counts, ordered status segments, existing management-dialog actions and a sorting explanation. Manifest ordinals remain unchanged by search filtering.

Only the ordinal is draggable. Drag-over changes LibraryPage-local preview order, not Topic state or Host data. Drop submits one existing reorder through WorkspaceApp's `manage()` and clears preview after completion; failures return to the authoritative order and retain the existing error/retry path. Cancelled drags submit nothing. Repeated drag-over on the same target does not oscillate the preview. Alt+Arrow delegates to `moveSource` and keeps title focus. Drag, keyboard and menu moves share busy/search/card-view guards, centralized in `topic-view.ts`; step 5 will add its status-filter guard. Upload drag handlers only accept Files, not Topic drags.

No contracts, Core, Host, Python, prototypes or spec files changed. No new persistence, polling or dependencies. FLIP is deferred to the motion step; it is optional in step 4. Screenshots were explicitly waived. Browser geometry, native drag behavior and touch/assistive-technology behavior are not claimed as verified: the existing isolated fixture is blocked by missing `.agents/skills/focus-read/scripts/focus_read.py`, local Chromium socket restrictions remain, and the cloud browser cannot reach this isolated Vite environment.
