# 统一精读完成与重新阅读

2026-11-23 确认。精读计划的已读段数统一决定阅读完成和知识库电量，避免独立的来源完成标记与精读进度给出不同结果。只有当前 Reading Plan 的全部 Chunk 已读完时才显示「已读完」。历史独立完成记录留档并退出当前状态投影，保留真实的历史精读进度。读者进入第一段后即处于「阅读中」，此时已读段数仍可为零。

在精读的当前前沿，读者主动滚动触达末段正文底部时，Core 提交一次末段完成。末段正文无需滚动即可完整看见时，读者可操作正文末尾的行内「读完」。对话、证据导航、程序滚动、重新布局、切换阅读方式、重新连接和离开页面均保持 Reading Cursor 与进度。已完成来源重新打开时继续展示已读全文。

「重新阅读」合并原来的新会话与重新规划入口。读者确认后先对当前选中的整轮阅读状态做结构化备份，每轮只保留最近一次成功备份的内容和时间，成功后按本篇创建顺序追加新一轮。从旧轮发起时，以该轮最近保存的内容为起点，所有已有轮次保留。旧计划、进度、译文、笔记、重点与对话可通过论文管理切换阅读版本查看。新一轮沿用原始来源并获得整篇笔记的独立副本，小段笔记、句子备注和重点从空开始。旧讨论随原阅读版本保存，切回时可从该轮进度继续阅读、编辑笔记并续接原讨论，变更仅写入该轮。新讨论从空白上下文开始，模型只使用该讨论的消息和摘要作为对话历史。确认后立即重新规划、重新划分小段并为外文来源重新翻译。按[设计文档 04 §1](../design/20261122-refactor/04-conversation-reading-bilingual-view.md#1-上传翻译与重新阅读)，本轮全部准备就绪后同时开放对话与精读。失败后可以重试。重置沿用可恢复提交和旧写入隔离，生成重试复用本轮重置结果。

本决定覆盖 ADR 0034 的独立来源完成规则，以及 ADR 0018 的旧重新阅读规则和独立新会话入口。工作台行为及验收见 [设计文档 02](../design/20261122-refactor/02_focus_statusbar_and_core_logic_refactor_design.md)。
