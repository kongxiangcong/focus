# Blog Output 仅保留带读博客

2026-10-20，用户决定从 FOCUS 移除价值分析技能与流程，将 Blog Output 简化为 Reading Blog 与单页 HTML。article-blog-v2 删除适用性判定、专用实现检索、条件文章及其重试和界面；保留来源证据、引用校验、写入授权和失败隔离。本决定取代 ADR 0013 的双产物与条件生成规则。

已有价值分析 Markdown、实现证据和旧 HTML 原样保留，不在启动或读取时批量迁移。兼容读取 v1 来源绑定及保留产物状态；用户明确重新生成或渲染时才发布 v2 元数据与单页 HTML。退役步骤不能继续执行或阻塞现行状态。全局安装技能不属于本次范围。
