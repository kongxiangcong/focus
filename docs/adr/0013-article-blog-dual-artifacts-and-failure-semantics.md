# article-blog 双产物、条件生成与失败重试语义

阶段 2 博客步骤由统一方法入口 article-blog 承担：Reading Blog（带读博客）每篇论文必产，Value Analysis（论文价值分析）仅在论文涉及硬件架构／DSE／编译器／仿真器／性能建模任一方向时生成，不适用则跳过并在合并 HTML 的对应页面显示不适用说明。两篇 Markdown 是权威中间产物，`index.html` 只是它们的合并渲染；HTML 的首要验收是在 FOCUS 工作台内嵌查看器中可打开显示，而非本地 file:// 双击。价值分析方法要求检索官方实现，但多宿主联网能力不一致，故检索为条件执行：有网则检索并静态核查，无网降级为"仅论文阅读"并如实记录检索范围与缺口，不因此判步骤失败。

## Considered Options

- 两篇均无条件生成：被否决。对纯算法论文强行产出架构价值分析会编造研究空白，违背价值分析手册"不强行制造研究空白"的原则。
- 不适用时显示空 tab 或隐藏 tab：被否决。统一保留"论文价值分析"页并展示不适用说明与判定理由，产物集合形态稳定、用户对跳过原因可见。
- 实现检索必选（无网即失败）：被否决。手册本身允许"访问不了应记录检索范围和缺口"，且不应引入宿主能力分叉。
- 保留历史版本快照：被否决。v0.2 最小实现为覆盖写，仅 metadata.json 记录各产物状态、生成时间与方法版本。

## Consequences

2026-09-26 阶段 5 grill Q3、Q6 扩展并澄清：Reading Blog 同时适用于 Paper Source 和 Article Source；Value Analysis 根据上述领域及原文依据判断适用性，不按 PDF／HTML 判断，页面统一称“架构价值分析”。非论文来源解释工程设计与边界，不虚构实验或论文贡献。保留以下失败语义及无人工核查规则；阶段发布仍需真实 Parser／Runtime 与浏览器完整流程，自动校验通过不代表解释深度与内容质量已证实。这是已确认需求，不是实现或验收声明。

- 重试粒度为单篇文档：一篇成功一篇失败时保留成功篇，只重跑失败篇再重渲染 index.html；渲染失败不污染两篇 md；任何博客失败不删 Bundle 与旧 HTML（沿用 ADR-0011 授权语义）。
- 不做人工质量核查；自动校验器只验形态合格（结构、图片实际解码、引用可解析、平台可渲染），深度与证据质量以警告形式如实呈现，不冒充质量验收通过。
- 旧 `.agents/skills/paper2blog/` 资产随 methods/article-blog/ 资源包建立而迁移废弃；CONTEXT.md 已收录 Reading Blog／Value Analysis／article-blog 术语。
