## 本阶段交付

按实际优先级、凭据和公开接口条件逐个接入 OpenAI、Pi、WorkBuddy；每个适配器单独经过需求讨论、spec、tickets 和验收。参考 Codex 与 DSH Runtime 也列入同一能力矩阵。

区分 Host、Agent Runtime、模型和凭据。OpenAI 路径先明确使用 Agents SDK 还是普通模型客户端及谁拥有工具循环；固定输出适配不扩展成通用 harness。WorkBuddy 不能以 CodeBuddy 或 fake SDK 验收替代。

## 验收出口

- 每项声明记录实际版本、认证方式及已验证的工具限制、图像、流式、取消、恢复和结果契约；能力不足预检查阻止任务，不静默降级。
- 同一业务流程通过来源隔离、输出／引用校验、幂等及失败语义测试，真实博客／解释／备注质量达标才标为完整支持。
- 空闲时切换用于后续任务／新会话；运行中先停止并确认业务断点，再开新 attempt。旧凭据、原生 session ID 和迟到事件不泄漏到新配置。
- 取消后的实际远端执行状态可见，业务层始终禁止已取消 attempt 提交；保留合法阶段产物。
- 真实调用证据与 fixture 结果分开；授权或接口未就绪的适配器留在待接入状态，不拖住公共工作流发布。
