# 阶段 4：新精读流程

状态：待 grill。依据：总计划 §1、§7，P3。依赖：阶段 3 的 Source Notes 和阶段 1 的提交规则。

## 用户结果与范围

用户明确进入精读才创建或复用原文锚定 Reading Plan；一次展示当前 Chunk，需要翻译时只准备目标 Chunk 并缓存，中文直接展示原文。当前 Chunk 可以追问，Notes 复用阶段 3 的 Source 资产。

保留固定 Chunk、Plan Glossary、原文引用和 Continue Reading 的唯一推进权威。替代 ADR 0010 的“全文准备后打开／继续”门槛，复用已有逐 Chunk 保存、失败恢复、幂等及旧 Plan 保留能力。

## 验收出口

- 入库、博客和整篇问答都不触发规划；显式进入精读后可复用有效 Plan。
- 首次进入及继续只为目标 Chunk 按需翻译；缓存命中不重复调用模型，不按 Chunk 序号错误复用其他 Plan 的译文。
- 明确的 Continue Reading 只推进一次；普通问题、概念理解确认和“继续解释”不推进。重复请求、断线重试和过期回执有确定结果。
- 翻译失败／取消时不跳过待读 Chunk，不误显示完成；重试恢复到同一目标。准备与游标提交次序需由 spec 明确并测试。
- 一次只展示当前阅读 Chunk；原文／译文切换、公式图片和来源定位可用。历史聊天与旧引用仍可访问，其呈现不得引入第二游标。
- 重读及重建计划保留 Source Notes、旧引用和合法历史产物；跨 Source／Topic 推进不要求预译整个 Topic。
