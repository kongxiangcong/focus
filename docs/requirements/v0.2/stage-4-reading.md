# 阶段 4：新精读流程

状态：grill 已收敛（2026-09-25，Q1–Q18 已回答），用户随后调用 to-spec 进入规格阶段；[阶段 4 spec](../../../.scratch/focus-v02-stage4/spec.md) 已发布为 ready-for-agent，测试边界已确认。依据：总计划 §1、§7，P3，及下方本轮修订。依赖：阶段 3 的 Source Notes 和阶段 1 的提交规则；此状态不代表实施或验收完成。

## 用户结果与范围

用户明确进入精读才创建或复用原文锚定 Reading Plan；一次点击授权规划和翻译准备，不增加计划确认页。Plan 与分块生成后，立即为该 Plan 的所有需翻译 Chunk 准备并缓存译文；翻译需基于全文语境保持连贯，不把 Chunk 当作孤立文本。中文直接展示原文。当前 Chunk 可以追问，Notes 复用阶段 3 的 Source 资产。准备完成只在界面右下角提示“{Source} 已就绪”，不自动打开、不抢占当前页面、不改变阅读选择；用户手动打开时使用准备结果。此规则修订 Q1 最初的自动展示建议。

保留固定 Chunk、Plan Glossary、原文引用和 Continue Reading 的唯一推进权威；复用已有逐 Chunk 保存、失败恢复、幂等及旧 Plan 保留能力。精读初始化等待当前 Source 整个 Plan 准备完成后才打开，保留 ADR 0010 的全 Plan 就绪门槛；首次等待换取后续推进不再等待翻译，禁止将准备范围扩展为整个 Topic。

翻译前通读全文，确定文章结构、Plan Glossary、符号含义与跨段指代；按 Chunk 翻译时使用全文语境，完成后检查跨 Chunk 术语和衔接。验收检查无漏译、术语一致、指代正确、公式图注对应和分段衔接自然，不以模型自称理解全文作为证据，也不要求单次调用输出全部译文。

默认规划正文及其中图表、脚注，附录纳入阅读；参考文献列表保留可查，不逐条精读。Chunk 按一个主要理解任务的最小连续范围划分，保护完整推导、公式和图表单元，不为固定字数截断。用户选择章节／段落／概念等分块粒度留作全部当前功能完成后的增量开发，本阶段不实现，也不要求预建配置或通用扩展框架。

## 恢复、复用与重建

初始化失败或取消后保留已提交的 Plan、全文语境准备和译文；显式恢复时补缺失部分，再完成连贯性检查。关闭网页不等于取消，Host 仍运行时继续准备；显式取消或 Host 重启后等待用户点击恢复，不自行重启模型任务。取消后的迟到结果不得提交。

初始化期间允许修正连贯性检查发现的受影响译文，再检查一致性；修复次数必须有上限，具体数值留给 spec。超过上限仍不通过时保留进展并报告失败，不宣称就绪。已经交付阅读的译文不因后台检查而静默改变。

更换模型或升级方法不自动废弃已就绪产物，只影响新任务。Bundle 内容改变时保留旧 Plan 与译文作为历史，不得冒充新版；显式修改术语译法需要重新准备受影响译文，本阶段不增加独立术语编辑器。

从头重读只回到同一 Plan 首段，保留译文与 Source Notes。重建先准备新 Plan，全部就绪后仍等待用户手动打开，再切换至新 Plan 首段；失败或取消时原 Plan 与当前位置保持可用，成功后旧资产和引用仍保留。候选 Plan 的准备及就绪通知不提前替换正式阅读选择。

同一当前位置发出的重复推进合并为一次，不支持连续跳段；只有拿到新位置后再次明确继续才允许下一次推进。断线重试返回原请求结果，过期页面操作提示刷新且不推进。具体请求、版本与回执字段由 spec 定义。

## 完成与导航

展示最后一个 Chunk 不自动标记完成，用户通过“完成本篇”按钮明确完成。完成后显示完成页，提供“从头重读”和历史引用／Notes 入口；再次普通打开仍显示完成页，不重置进度或重译。完成页不显示“开始下一篇”按钮，不自动启动其他 Source 的准备。

左侧进度条点击只改变展示内容，不改变 Reading Cursor 或完成状态；可以围绕所查看的 Chunk 提问，但不能从该历史位置继续推进。尚未完成时只允许点击已经读过的 Chunk，未读 Chunk 不可点击，不能借此预览后文；已完成后可查看全部 Chunk。提供返回当前阅读的入口；只有显式从头重读才重置正式进度，浏览位置不是第二游标。

## 验收出口

- 入库、博客和整篇问答都不触发规划；显式进入精读后可复用有效 Plan。
- 进入精读后主动准备当前 Source 整个 Plan 的译文并完成连贯性检查，全 Plan 就绪后才首次展示；缓存命中不重复调用模型，不按 Chunk 序号错误复用其他 Plan 的译文。中断后保留合法进展，恢复不重复生成已提交且有效的内容。
- 明确的 Continue Reading 只推进一次；普通问题、概念理解确认和“继续解释”不推进。重复请求、断线重试和过期回执有确定结果。
- 翻译失败／取消时不跳过待读 Chunk，不误显示完成；重试恢复到同一目标。准备与游标提交次序需由 spec 明确并测试。
- 主阅读区一次只展示一个 Chunk，正常为正式当前 Chunk，也可只读查看进度条选中的已读 Chunk；默认译文，卡片按钮可切换原文。未读 Chunk 不可通过进度条访问，不提供绕过翻译准备的独立原文阅读模式。公式图片和来源定位可用。历史聊天与旧引用仍可只读查看，不回退 Reading Cursor、不提供从历史位置继续的入口。
- 重读及重建计划保留 Source Notes、旧引用和合法历史产物；跨 Source／Topic 推进不要求预译整个 Topic。
- 最后一段通过“完成本篇”显式完成，再次打开显示完成页，提供从头重读和历史引用／Notes，不显示开始下一篇按钮。已完成状态不因查看历史 Chunk 改变。
- 初始化或重建准备完成只提示就绪，不自动打开或改变阅读选择；手动打开复用准备结果。

## Grill 决策记录（2026-09-25）

- Q1：同意一次点击进入精读即授权规划与准备，不增加计划确认页；最初包含的自动展示建议由 Q16 修订为就绪通知后手动打开。
- Q2：用户修订原按目标 Chunk 翻译方向，要求 Plan 分块后立即为每个 Chunk 翻译，以减少推进等待；要求先理解全文语境，避免孤立分块翻译不连贯。展示门槛由 Q5 确定。
- Q3：不提供独立原文阅读选项；阅读卡片默认显示译文，支持按钮切换对应原文。此切换不构成跳过翻译准备的路径。
- Q4：同意只读历史查看，不回退到旧历史阅读位置。
- Q5：选择全部准备完成再打开。用户愿意等待初始化阶段“上菜”，不希望开始阅读后反复等待翻译打断心流。
- Q6：同意全文语境准备、按 Chunk 翻译及最终连贯性检查的过程与验收标准。
- Q7：同意默认规划范围和分块尺度；用户可选章节／段落／概念粒度仅记录为后续增量，不在当前实现。
- Q8：Topic 中只准备当前进入精读的 Source，跨篇时才准备下一篇，不预译整个 Topic。
- Q9：同意保留合法提交并恢复缺失部分；关闭网页不取消，显式取消或 Host 重启后须手动恢复，拒绝取消后的迟到提交。
- Q10：同意初始化内有限修复并复查；失败不宣称就绪，交付后的译文不被后台静默改写。
- Q11：同意模型／方法变化不自动废弃已有产物，Bundle 变化隔离旧资产，术语修改须显式重新准备；本阶段不做术语编辑器。
- Q12：同意同 Plan 从头重读保留资产；新 Plan 全部就绪才可替换阅读选择，重建失败或取消保留原 Plan 与位置；结合 Q16，替换发生在用户手动打开时。
- Q13：同意重复推进合并、重试返回原结果、过期请求不推进；用户明确不支持连续跳段。
- Q14：增加“完成本篇”按钮，不显示“开始下一篇”按钮。
- Q15：已完成 Source 显示完成页，提供从头重读和历史引用／Notes；左侧进度条允许点击查看对应 Chunk，具体阅读状态语义由 Q17–Q18 确定。
- Q16：就绪后仅在右下角显示“{Source} 已就绪”提示，不自动跳转或改变阅读选择；只能用户手动打开并使用准备结果。
- Q17：同意进度条点击只读查看，不改变 Reading Cursor 或完成状态，可针对查看内容提问，不从历史位置继续。
- Q18：未完成时仅可点击已读 Chunk，禁止点击未读 Chunk；完成后可查看全部 Chunk。此决定拒绝了未完成时允许预览后文的建议。
