# 阶段 5B：批量 Inbox

状态：待 grill。依据：总计划 §1、P3。依赖：阶段 1、2；双格式批量发布需 5A。

## 本阶段交付

用户选择多份待处理文档，检查目标 Topic 和处理范围，一次明确确认后逐项进入已有入库与博客流程。批量是多个单篇业务的组织方式，共用确认、发布和重试规则；不要求并行执行或引入通用调度平台。

## 验收出口

- 未选中或未确认的项不外发；确认后的新增／替换文件不自动获得授权。
- 每项显示待处理、处理中、已完成／失败／取消及所在业务阶段；部分成功不伪装成全部成功。
- 一项失败不破坏成功项的 Bundle／Blog；只重试失败或未提交步骤，重复文件复用稳定 Source。
- 刷新／重启后可识别已提交项和剩余项，不盲目重放远端上传或正式写入。
- 单项及整批停止的作用范围明确，取消 attempt 的迟到结果不提交；已提交合法产物保留。
- 每份成功文档都可独立打开来源和后续阅读，不以整批完成作为访问条件。
