# 阶段 2：入库后生成博客

状态：待 grill。依据：总计划 §1、§3.3、P2。依赖：阶段 1。

## 用户结果与范围

已发布 Bundle 进入独立博客步骤，生成写作证据笔记／Evidence Map、中文细读长文和单文件 HTML，用户能在独立网页查看并核查来源。按阶段 0／1 明确的授权边界启动，不把一次确认解释成任意外发授权。

复用 paper2blog 的证据、方法解释、图表分析、边界说明和渲染校验；新方法资源按 `article-blog` 的统一入口组织，首轮覆盖 PDF，HTML 在 5A 补齐。写作证据笔记与用户 Reading Notes 分开，生成博客不依赖 Reading Plan、Cursor 或私人阅读记录。

博客工作流纳入同一 Application，绑定 Source／Bundle 和方法版本。正式发布前由共用校验器检查候选产物；Runtime 说“完成”不等于博客已发布。

## 验收出口

- 同一有效 Bundle 能生成、展示中文长文及配套 Evidence Map／HTML；重要主张、公式、图表和数值可追溯到来源。
- 实际检查关键图片，而不是仅凭文件名推断；能力不足或必要证据缺失可见，不冒充质量验收通过。
- 区分原文结论、解释性推论和局限；文章满足既有写作方法的深度要求，不用机械长度代替质量。
- 单文件 HTML 在约定的独立打开条件下展示正文、图片和必要样式；具体依赖与导出验收在 grill 确定，不能把仅返回 HTML 路径当作通过。
- 博客失败、取消、无效引用不删除或重传 Bundle；只重试未提交博客步骤，重复请求不重复发布。已有合法博客在失败重生成时仍可访问。
- 没有 Plan 也能完成博客；不创建全文翻译任务、不写用户备注或游标。
