# 入库后生成带读博客

现行需求更新于 2026-10-20，依据 ADR 0029；历史阶段验收记录保持原样。

## 产物与触发

有效 Paper Source 或 Article Source 的 Parser Bundle 可生成中文技术细读长文 `blog.md`、写作证据 `evidence/evidence-map.md`、引用图片 `assets/`、元数据 `metadata.json` 与单页自包含 `index.html`。博客正文是权威中间产物，HTML 为其派生展示。

入库确认勾选“同时生成博客”后接续生成，也可在 Source 详情手动触发。授权、来源身份与 Bundle 绑定由共享 Application/Core 负责；独立于 Reading Plan、Cursor、翻译和私人 Reading Notes。

## 生成与展示

唯一方法包为 `methods/article-blog/`，版本 article-blog-v2；依次准备候选、生成带读博客、校验、渲染、发布。工作台只显示带读博客和 HTML 两项状态，失败按产物重试，成功后可主动重新生成。生成过程中阅读仍可使用。

HTML 在工作台内嵌查看器中显示；CSS、JS、图片和公式渲染资源内嵌。正文保留可解析的文献引用、原文结论与解释性推论的区分，内部原文锚点和证据缺口记录留在证据文件及 metadata，不显示为阅读正文或审计页脚。

## 验收

- 校验正文骨架、可解析引用、图片实际解码及来源绑定、自包含单页 HTML；深度与证据质量不能机械判定，警告不等于质量通过。
- 渲染失败不污染 Markdown；生成失败、取消、无效引用不删除 Parser Bundle。旧合法 HTML 在重生成失败时仍可打开。
- 重复请求不重复发布；取消后到达的候选不能提交；只有授权写者可发布。
- 兼容读取 v1 状态，不自动修改旧文件；明确重新生成或渲染后升级为 v2。旧额外产物不参与运行、校验和界面展示。
