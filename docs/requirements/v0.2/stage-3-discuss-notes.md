# 阶段 3：整篇问答与独立备注

2026-10-08 修订：用户要求讨论同时支持绑定原文检索和联网补充。[ADR 0022](../../adr/0022-source-discussion-web-evidence.md) 取代本文历史决策中的“默认不自动外网检索”：讨论可按问题需要调用原生网页工具，区分原文、外部资料与推断，为外部证据附链接；来源绑定、阅读进度和显式笔记规则保持原有语义。

## 用户结果与范围

用户围绕整篇原文自由提问、逐概念解释，并将值得保留的讨论提炼为 Source 级 Reading Note。即使尚未进入精读、没有 Plan／Chunk，也能完成“提问→取证解释→保存备注→查看／编辑／撤销”。博客提供阅读入口，原文 Bundle 才是来源证据。

复用原文范围读取和有界检索，补齐显式 Source／Bundle 范围与无 Plan 的上下文。用户备注只有一份 Source 级权威，不复制到每个 Topic 或新 Plan；写作证据笔记保持隔离。宿主保存原始聊天，Core 只保存精简阅读资产。

阅读过程保留两个层次的资产：第一层是用户明确说“记下来”或表达同等记录意图时保存的 Source 级 Reading Note，可包含理解链、澄清的概念、辅助解释的例子或尚未解决的问题；第二层是每个 Chunk 推进或完成本篇时由系统简短保存的 Reading Progress Entry（阅读进度记录）。后者记录本段阅读与讨论进度，不作为另一套阅读游标或能力评价。

不在每轮回答后自动保存 Reading Note。对 A→B→C 被纠正为 A→D→C 的讨论，不自动保留用户尚未确认理解的纠正；将纠正保存为用户自己的理解须有用户明确表达接受。主动笔记以明确记录意图为触发，无需再次确认；允许用户明确要求保留尚未理解的问题。两类记录均以低打扰方式完成。

## 问答与记录行为（已确认）

- 解释允许使用通用知识、类比与例子，优先结合例子减少阅读负担；默认不自动外网检索。问答正文默认不展示引用材料，系统内部仍须读取和校验来源，区分原文支持、解释性推论与补充背景；证据不足时简短说明。此展示规则针对 Stage 3 问答，不修改 Stage 2 博客的引用要求。
- 阅读进度记录侧重“读过哪里、讨论过什么”。仅在用户明确表达理解时记录该表达，不把点击下一段当成理解确认，也不由模型判定用户已经理解。没有讨论时只记录读过该段。
- 无 Plan／Chunk 的整篇问答仅支持主动笔记；关闭聊天或切换 Source 不触发被动记录。
- 推进 Chunk 和“完成本篇”均触发进度记录；记录生成失败不阻塞推进，提示未保存并允许重试，重试只补记录、不再次推进。这里的记录是阅读进度，不是论文或文章的摘要，不要求来源含摘要。
- “记下来”默认整理当前话题，一般采用“例子＋总结后的结论”；保留必要的理解链，不复制来回追问。只有明确要求整理刚才全部讨论时才覆盖多个话题，不再次询问确认。
- 同一概念再次要求记录时追加新笔记，不自动改写或合并旧笔记。用户编辑优先，后续内容与旧笔记矛盾时可在新增笔记中用括号简短标注；编辑既有笔记须有明确编辑意图。
- 阅读进度记录默认收在对应 Chunk 的“阅读记录”入口，按需展开，允许更正或删除；更正后不被自动覆盖。从头重读保留此前记录，新一轮另记；重建 Plan 后旧记录仍归旧 Plan，Source 级主动笔记继续共享。
- 内部引用绑定原来的 Bundle 版本，重新解析后保留笔记和旧引用，不自动套用新行号；受影响笔记简短标注“来源已更新，待核对”。默认隐藏引用材料，用户主动要求看出处时才展开。
- 撤销以单条主动笔记为单位：新增可撤销、修改可恢复前一版、删除可恢复；刷新或重开后仍有效。至少保留最近一次可恢复状态，首版不提供完整历史浏览器。

## 归属、失败与恢复（已确认）

- 每次问答和保存请求绑定发起时的 Source 及对应 Bundle；进度记录还绑定对应 Plan／Chunk 和阅读轮次。切换文章后，原任务可以继续完成，但回答与记录只归原文章，不进入新文章的聊天或笔记，不自动跳回原文章。不能因提交时当前选择已变化而写错归属。
- 明确取消后不保存迟到结果；失败重试不重复写入。用户再次明确说“记下来”是一次新的追加意图，与同一请求的断线重试区分。
- 主动笔记保存成功仅轻量提示“已记下”，失败显示“未保存，可重试”；不能将模型已生成内容等同于已保存。进度记录成功时不提示，失败时采用不打断阅读的提示。
- 编辑冲突保留当前输入，不覆盖已保存版本，提供查看与重新提交入口。问答和记录失败不修改 Bundle／Blog，不创建 Plan，也不改变游标；显式推进成功后，补记失败不回滚推进。

## 验收出口

- 无 Plan 的 Source 可检索原文并回答问题；证据不足明确说明，错误／失效引用不被保存成可靠证据。
- 用户明确要求记录的理解链、概念、例子或疑问形成离开聊天仍可读懂的简洁备注；未经确认理解的纠正不自动保留。Chunk 推进时的阅读进度记录与主动笔记明确区分，不保存讨论全文或能力评价。
- Notes 可查看、编辑和撤销；保存／重复请求不重复写入，编辑冲突可见；自动整理与用户编辑的覆盖关系明确。
- 问答失败、取消或重试不影响 Bundle／Blog；不创建 Plan、不改变任何 Source 的精读游标。
- 为一个 Source 建立或重建 Plan 后，同一 Notes 仍可访问；Topic 切换不产生备注副本。
- 切换 A→B 后 A 的迟到回答和笔记仍只归 A；取消后不保存迟到结果，重复请求不重复写入，再次主动记录则追加。
- 阅读进度记录按 Chunk 推进／完成本篇生成，默认收起，可更正或删除；重读另记，重建 Plan 保留旧记录；生成失败和补记重试均不额外推进。
- 默认解释结合例子、隐藏引用材料；主动笔记通常呈现例子与总结后的结论。内部仍校验原文，来源更新提示待核对，用户要求出处时能查看原绑定版本的引用。

## 分层验收（已确认）

- 行为验证：无 Plan 问答、显式保存、追加、编辑撤销、引用失效、重试和取消、跨文章隔离，以及进度补记不重复推进。
- 浏览器体验：实际走通问答与两类记录，确认无频繁确认弹窗、无跨文章污染，成功／失败和冲突提示符合低打扰要求。
- 真实模型质量：至少选一篇论文和一篇普通文章，核查“例子＋结论”的准确性、未接受纠正是否被误存、是否擅自判断用户理解。模拟测试通过不替代真实解释质量验收。

## Grill 决策记录（2026-09-25）

- Q1–Q2：用户先同意自动整理建议，随后明确以双层记录修订触发规则：主动笔记只由明确记录意图触发；被动阅读过程摘要在每个 Chunk 推进时简短生成。撤回每轮回答后自动保存备注及保留未接受纠正的建议。
- Q3：同意通用知识和类比、区分证据与推论、默认不自动外网检索；用户补充不展示引用材料，优先结合例子解释。
- Q4：同意用户编辑优先与可见补充，冲突可在括号里标注；主动笔记触发仍以 Q2／Q6 为准。
- Q5：同意单条笔记最近一次可恢复状态，支持刷新或重开后的撤销，不做完整历史浏览器。
- Q6：同意明确要求即可保存疑问等内容，不要求全部先理解；用户强调记录无感、无需额外确认，主动笔记仅在明确要求时保存。
- Q7：同意没有理解表达时只记阅读与实际讨论，不把推进当成理解；被动记录偏向阅读进度，理解仅依据用户表达记录。
- Q8：同意无 Chunk 的整篇问答不生成被动记录。
- Q9：同意记录失败仍可推进、可独立重试补记、完成本篇也触发记录；用户强调来源也包括普通文章。将“阅读过程摘要”改称“阅读进度记录”，避免与来源摘要混淆。
- Q10：同意默认保存当前话题的最终要点，用户补充一般采用“例子＋总结后的结论”。
- Q11：再次记录同一概念时追加，不自动合并或改写。
- Q12：同意进度记录默认收起、可更正或删除、更正后不自动覆盖；重读另记，重建后旧记录归旧 Plan，主动笔记共享。
- Q13：同意内部引用绑定原 Bundle 版本；来源更新保留旧笔记和引用并简短提示，主动要求出处时才展开。
- Q14：同意切换文章后原任务可继续、结果只归原文章、不跳转；取消后不保存迟到结果、重试不重复写入。用户强调不同文章的笔记互不影响，不能记录到错误文章。
- Q15：同意主动笔记保存轻量反馈、失败可重试、编辑冲突保留输入并提供处理入口；进度记录成功无提示、失败不打断阅读。
- Q16：同意行为验证、浏览器体验与真实模型质量三层验收；真实样本至少含论文和普通文章，模拟测试不替代质量验收。
- 用户确认最终共识并要求按顺序执行 to-spec、to-tickets；不代表实现或验收通过。
