# 博客阅读重点与排版

Reading Blog 与 Value Analysis 在生成正文时，依据完整来源语境自动选择专业术语、机制、关键结论和适用边界。术语使用 Markdown 粗体，少量关键短句使用 `==高亮==`。不能用固定词表替代文章理解，不为排版改变事实、条件或结论强度。

两篇正文共享运行规则 `methods/article-blog/reference/reading-format.md`。主标题、章节、子章节分别使用一至三级 Markdown 标题；段落、列表、表格保留技术解释的完整性。默认限制强调密度，避免整段加粗、高亮或反复标注同一术语。

HTML 使用中文系统字体、适中的阅读宽度与行距；主标题突出、章节带蓝色侧边线、子标题使用更小的蓝色字体，重点短句使用浅黄色背景。样式同时作用于两篇文章，窄屏保持可读。正文、列表、引用、表格均支持强调；代码、公式、链接地址、图片路径保持原义，原始 HTML 仍按文本转义。

样式参考：[CIMFlow 文章](https://www.eet-china.com/mp/a483200.html) 的标题层级、蓝色章节强调与术语粗体；不复制文章正文或外部字体资源。

新生成或重新生成的正文应用语义标注规则。已保存的正文不会自动改写；单独重新渲染 HTML 仅应用样式和已有标记。仍沿用单篇重试与 Core 发布边界，不修改 Parser Bundle、Reading Plan 或阅读位置。模型遵循规则与重点选择的内容质量须与渲染、自动化测试证据分开报告。
