## 核心行为与存储一致性

- 前沿游标与显示段落分开。历史继续不修改前沿、阅读 revision 或补记；到前沿后衔接真实下一段。已完成状态保持完成，末尾显示已读完，避免无响应继续或自动循环。
- 从未展示第一段时继续先打开第一段；正常新会话从前沿下一段开始。新会话隐藏当前空间，并保存清屏状态，刷新不恢复旧卡片。已有讨论、译文、博客、笔记、阅读记录保留。
- 重新阅读可针对非当前来源执行。只清除目标讨论、笔记、阅读记录及对应补记请求/恢复副本，游标初始化为当前计划第一段、reading_started=false，下一次继续展示第一段。原文、计划、译文、博客及其他来源保留。
- 重新阅读采用持久清理日志，核心重置带 requestId 幂等栅栏，更新轮次/revision；活动写者先拒绝，不允许迟到结果复活旧记录。中断恢复会完成目标清理。
- 新计划仅显式激活；引用和补记包含计划归属。兼容接口的旧“仅清讨论”语义仍单独保留，网页重新阅读通过 resetReading=true 进入新语义。
- 语义冲突通过 [ADR 0018](../adr/0018-confirmed-reader-operation-semantics.md) 记录，更新 CONTEXT.md 术语，不暗改历史 ADR。

## 未验证项和阻塞项

## 后续视觉审查修正（2026-09-30）

用户指出状态栏遮挡博客关闭、任务状态重复展示和阅读标题横向滚动增加信息负担。本次按新指示调整展示层，原始已确认方案保留；布局规则更新见 ADR 0018 的 visual refinement。

- 状态摘要并入标题/选择器行；移除独立状态条及其高层级遮挡。
- 一个下箭头入口统一展开、收起工作详情、批次和单项上传。默认全部收起，展开后批次仍可分别收起；同一解析任务不重复展示。
- 删除独立横向滚动标题及阅读底部重复标题。准备细节收进“详细”，主按钮继续反馈准备中/重试。
- 统一页面背景、工具栏、间距、圆角和边框；阅读正文保留阅读字体。
- 博客使用 showModal 进入浏览器顶层；关闭与 Escape 都明确关闭模态并返回原页面。

本轮验证：97 项前端测试通过（37 reader-ui + 60 standalone），类型检查和生产构建通过。浏览器原有 8 组流程继续通过，另增任务默认收起/标题同排及桌面、390px 宽博客关闭点击目标、Escape 验证。博客摘要、iframe 内容和批次为确定性展示夹具，不能据此声称真实博客生成或 MinerU 链路已验收。中文截图仍受测试环境字库限制。本轮没有修改后端业务逻辑，也没有重新运行全量 Python；原回归基线与真实服务验收边界仍有效。
