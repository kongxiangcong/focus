# FOCUS Paper Learning

FOCUS separates reading investment, observable learning evidence, source truth, and cross-paper research knowledge so none can silently stand in for another.

## Language

**Scout**:
The default low-cost reading mode used to decide whether a paper deserves further investment.
_Avoid_: Quick mastery, shallow Study

**Study**:
A reading mode that builds research-usable understanding of key mechanisms, evidence, boundaries, and critique without exhaustive defense.
_Avoid_: Mastery-lite, deep read

**Mastery**:
A reading mode reserved for core papers that require full dependency learning, frozen assessment, remediation, and delayed retrieval.
_Avoid_: Read completely, finished

**Provisional**:
Evidence that an immediate, source-anchored checkpoint passed; it permits learning continuity but proves neither independent reconstruction nor retention.
_Avoid_: Understood, almost mastered

**Verified-now**:
Evidence that the learner independently reconstructed or transferred the model in the current period through a frozen check.
_Avoid_: Mastered, retained

**Retained**:
Evidence that the learner independently reconstructed the model in a different persisted session at least seven days after verified-now.
_Avoid_: Remembered, mastered

**Paper Map**:
The smallest source-faithful model required by the selected reading mode, from a Scout overview to a Mastery dependency plan.
_Avoid_: Knowledge base, summary

**Cognitive Profile**:
A disposable UI projection rebuilt from append-only learner evidence; it never routes work or acts as evidence itself.
_Avoid_: Learner truth, mastery record

**Atlas Object**:
One canonical cross-paper Concept, Synthesis, Question, or Idea. Paper is a FOCUS projection, Claim stays paper-local, and Project/Experiment is a consumer.
_Avoid_: Note, Paper object, Claim object
